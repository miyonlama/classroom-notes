  1. Q1

    Create a class Employee with private data members Eid, Ename, and Salary. Include public member functions to read and display the values of these data members. Derive a class named Typist from the above class. The Typist class should contain an additional private data member. Finally, create two objects of the Typist class and read and display their values.

    Worked answer

    Employee owns the common data. Its public read() and display() functions are the only way in and out, so the private fields stay hidden. Typist : public Employee inherits those functions and adds its own private field. A Typist object contains an Employee subobject, so its own read() calls Employee::read() first.

    #include <iostream> using namespace std; class Employee { int Eid; char Ename[40]; float Salary; public: void read() { cout << "Employee id, name, salary: "; cin >> Eid >> Ename >> Salary; } void display() const { cout << Eid << " " << Ename << " " << Salary << endl; } }; class Typist : public Employee { int wordsPerMinute; public: void read() { Employee::read(); cout << "Typing speed: "; cin >> wordsPerMinute; } void display() const { Employee::display(); cout << "Typing speed: " << wordsPerMinute << endl; } }; int main() { Typist t1, t2; cout << "First typist\n"; t1.read(); cout << "Second typist\n"; t2.read(); cout << "\nFirst typist\n"; t1.display(); cout << "Second typist\n"; t2.display(); return 0; }

  2. Q2

    What is object-oriented programming? How does it differ from procedure-oriented programming? Explain the features of object-oriented programming.

    Worked answer

    Object-oriented programming (OOP) organises a program around objects: each object bundles state (data members) with the operations that may use that state (member functions). Procedure-oriented programming organises the program around functions that act on separate, often global, data. In OOP the data and its operations live together; in procedural code the flow of control and the data are separated.

    • Encapsulation: data and functions are wrapped in a class, with access specifiers protecting the representation.
    • Abstraction: a class exposes only the essential interface and hides implementation detail.
    • Inheritance: a derived class reuses and extends the members of a base class.
    • Polymorphism: one interface has many implementations; compile-time through overloading and templates, run-time through virtual functions.
    • Dynamic binding: a virtual call is resolved from the actual object type at run time.
    • Reusability and message passing: objects communicate through member function calls, so tested classes can be reused.

    Example: a Time object owns its hours, minutes and seconds; code cannot change those fields directly but calls show() or add().

  3. Q3

    Create a class called Time that has separate int member data for hours, minutes, and seconds. One constructor should initialize these members to 0, and another should initialize them to specific values. A member function should display the time in HH:MM:SS format. Another member function should add two Time objects passed as arguments. The main() program should create two initialized Time objects (should they be const?) and one uninitialized Time object. Then it should add the two initialized objects and store the result in the third Time variable. Finally, display the value of the third variable. Make appropriate member functions const.

    Worked answer

    The two source objects are read-only inputs, so declare them const Time. That is legal only if every function called on them is a const member function: make show() and add() const, and take the two operands by const Time&. The zero-argument constructor supplies the uninitialized (zero) object that receives the result. Total seconds are added first, then split back into hours, minutes and seconds.

    #include <iostream> #include <iomanip> using namespace std; class Time { int hours, minutes, seconds; public: Time() : hours(0), minutes(0), seconds(0) {} Time(int h, int m, int s) : hours(h), minutes(m), seconds(s) {} void show() const { cout << setfill('0') << setw(2) << hours << ':' << setw(2) << minutes << ':' << setw(2) << seconds << setfill(' ') << endl; } Time add(const Time& a, const Time& b) const { int total = (a.hours * 3600 + a.minutes * 60 + a.seconds) + (b.hours * 3600 + b.minutes * 60 + b.seconds); return Time(total / 3600, (total / 60) % 60, total % 60); } }; int main() { const Time t1(10, 45, 30), t2(2, 20, 45); Time result; result = result.add(t1, t2); cout << "t1 = "; t1.show(); cout << "t2 = "; t2.show(); cout << "sum = "; result.show(); return 0; }

  1. Q4

    Explain the memory management operators in C++ with examples.

    Worked answer

    C++ allocates dynamic memory on the free store with new and releases it with delete. new T allocates one object and calls its constructor; new T[n] allocates an array. delete calls one destructor and frees one object; delete[] calls every element destructor and frees the array. Mixing the scalar and array forms is undefined behaviour, and every new must be matched by exactly one delete.

    int* p = new int(7); // one int, initialised to 7 delete p; // free it int* a = new int[3]{1, 2, 3}; // array of three ints delete[] a; // free the whole array

  2. Q5

    Explain call by value and call by reference with appropriate examples.

    Worked answer

    With call by value the argument is copied into the parameter, so changes stay local to the called function. With call by reference the parameter is an alias for the caller's object, so changes are visible after the call. A const reference avoids copying large objects while forbidding modification.

    void byValue(int x) { x = 0; } // caller unchanged void byRef(int& x) { x = 0; } // caller changed void readOnly(const int& x) { /* no copy, no change */ } int n = 5; byValue(n); // n is still 5 byRef(n); // n is now 0

  3. Q6

    Describe types of constructors with examples.

    Worked answer

    A constructor has the class name, no return type, and runs when an object is created. The default constructor takes no arguments; the parameterised constructor takes values for initialisation; the copy constructor builds a new object from an existing one of the same class (its parameter is a reference). C++ also supplies a move constructor that takes resources from a temporary.

    class Box { int len; public: Box() : len(0) {} // default Box(int l) : len(l) {} // parameterised Box(const Box& b) : len(b.len) {} // copy int value() const { return len; } }; Box a; // default Box b(10); // parameterised Box c(b); // copy

  4. Q7

    Explain the use of objects as function arguments with an example.

    Worked answer

    Objects can be passed by value, by reference, or by const reference. By value the copy constructor runs, so the function cannot affect the original but pays for a copy. By reference no copy is made and the function may modify the original. A const reference is the usual choice for large read-only objects: no copy and no accidental change.

    void printByValue(Box b) { cout << b.value(); } // copy void grow(Box& b) { Box t(5); b = t; } // can modify void print(const Box& b) { cout << b.value(); } // no copy, read only

  5. Q8

    List various type-conversion techniques. Explain basic-to-user-defined type conversion with an example.

    Worked answer

    Techniques are implicit standard conversion (for example int to double), explicit C-style or static_cast conversion, a converting constructor for basic-to-user-defined conversion, and a conversion operator such as operator double() const for user-defined-to-basic conversion.

    For basic-to-user-defined conversion, give the class a constructor that takes one argument of the basic type. C++ uses that constructor automatically when a value of the basic type is supplied where the class is expected. Mark it explicit if implicit conversion would be surprising.

    class Distance { int metres; public: Distance(int m) : metres(m) {} // converting constructor int value() const { return metres; } }; Distance d = 12; // int -> Distance via Distance(int)

  6. Q9

    How does late binding differ from early binding? How can you achieve dynamic polymorphism? Explain with an example.

    Worked answer

    Early (static) binding resolves the function call at compile time. Ordinary functions, overloaded functions and templates use it. Late (dynamic) binding resolves the call at run time from the type of the actual object. Achieve it by declaring a base function virtual, overriding it in derived classes, and calling it through a pointer or reference to the base.

    class Shape { public: virtual void draw() const { cout << "shape\n"; } virtual ~Shape() {} }; class Circle : public Shape { public: void draw() const override { cout << "circle\n"; } }; Circle c; Shape* p = &c; p->draw(); // prints "circle": decided at run time

  7. Q10

    Explain pure virtual functions with an example.

    Worked answer

    A pure virtual function is declared with = 0 in the base class: virtual void area() const = 0;. It has no implementation in that class, so the class is abstract: no object of it can be created. Every concrete derived class must override the function or it too stays abstract. This forces a common interface on all shapes.

    class Shape { public: virtual double area() const = 0; // pure virtual virtual ~Shape() {} }; class Square : public Shape { double side; public: Square(double s) : side(s) {} double area() const override { return side * side; } }; Square s(4); // concrete: area() is 16
    [5]
  8. Q11

    What is exception handling? Explain how to handle an exception with an appropriate example.

    Worked answer

    Exception handling separates detection of an error from its treatment. Code that may fail goes in a try block. On error, throw raises a value; the first matching catch handles it. If no catch matches, stack unwinding continues and an uncaught exception calls terminate(). A catch (...) block catches anything.

    try { if (b == 0) throw "division by zero"; cout << a / b; } catch (const char* msg) { cerr << "Error: " << msg << endl; } catch (...) { cerr << "Unknown error" << endl; }

  9. Q12

    Write a program that copies the contents of file1 into file2.

    Worked answer

    Open file1.txt for input and file2.txt for output. Check both streams before use. Reading and writing one character at a time with get() and put() preserves every byte, including newlines, and stops cleanly at end of file. Close both streams when done.

    #include <iostream> #include <fstream> using namespace std; int main() { ifstream in("file1.txt"); ofstream out("file2.txt"); if (!in || !out) { cerr << "Cannot open file" << endl; return 1; } char ch; while (in.get(ch)) out.put(ch); in.close(); out.close(); cout << "Copied file1.txt into file2.txt" << endl; return 0; }

  1. Q1

    What are templates needed for? Why does a program terminate after an exception occurs? Describe the types of constructors.

    Worked answer

    Templates are needed to write one type-safe implementation that works for many data types. Without them we would duplicate the same function or class for int, double, and every other type. The compiler generates the needed version at compile time, so there is no run-time cost.

    An exception unwinds the stack looking for a matching catch. During unwinding, automatic objects are destroyed. If no handler matches, std::terminate() is called and the program ends; that is the language's way of refusing to continue with an unhandled error.

    Constructors are special functions that initialise a new object: the default constructor takes no arguments, the parameterised constructor accepts initial values, the copy constructor builds from another object of the same class, and the move constructor takes resources from a temporary.

    class Box { int len; public: Box() : len(0) {} // default Box(int l) : len(l) {} // parameterised Box(const Box& b) : len(b.len) {} // copy };

  2. Q2

    Differentiate between an abstract class and a concrete class. Write a program to create a class named Quadratic that represents a function of the form f(x) = ax^2 + bx + c, where x is a real variable and a, b, c are real constants. The class must satisfy the following requirements:

    1. Provide a constructor that takes values for a, b, and c as arguments; all three arguments should default to zero.
    2. Provide a function that takes a single argument x and returns the value of f(x).
    3. All data members should be private.
    Worked answer

    An abstract class has at least one pure virtual function, so it cannot be instantiated; it defines an interface that derived classes must complete. A concrete class has no unimplemented pure virtual function and can be instantiated directly.

    The Quadratic class below keeps a, b and c private, gives them default values of zero, and evaluates f(x) with Horner's form (a*x + b)*x + c. The default constructor call is legal because all three parameters have defaults.

    #include <iostream> using namespace std; class Quadratic { double a, b, c; // private by default, stated explicitly below public: Quadratic(double a = 0, double b = 0, double c = 0) : a(a), b(b), c(c) {} double value(double x) const { return (a * x + b) * x + c; // ax^2 + bx + c } void show() const { cout << "f(x) = " << a << "x^2 + " << b << "x + " << c << endl; } }; int main() { Quadratic q(2, -3, 1); Quadratic zero; // all three arguments default to 0 q.show(); cout << "f(3) = " << q.value(3) << endl; // 18 - 9 + 1 = 10 cout << "zero f(3) = " << zero.value(3) << endl; return 0; }

  3. Q3

    Explain the chain of constructors and destructors between subclasses and superclasses during inheritance with an example. Create a class named Point with data members x and y. Overload the + operator to add two objects of this class.

    Worked answer

    Construction runs top-down: the base class constructor first, then member object constructors, then the derived constructor body. Destruction runs bottom-up: the derived destructor first, then members, then the base destructor. The base constructor may be selected explicitly in the member initialiser list; otherwise its default constructor is used.

    class Base { public: Base() { cout << "Base ctor\n"; } ~Base() { cout << "Base dtor\n"; } }; class Derived : public Base { public: Derived() { cout << "Derived ctor\n"; } ~Derived() { cout << "Derived dtor\n"; } }; // Base ctor -> Derived ctor -> Derived dtor -> Base dtor

    The Point class stores x and y and defines a const member operator+. It returns a new Point whose coordinates are the sums of the operands; neither operand is changed.

    #include <iostream> using namespace std; class Point { int x, y; public: Point(int x = 0, int y = 0) : x(x), y(y) {} Point operator+(const Point& other) const { return Point(x + other.x, y + other.y); } void show() const { cout << "(" << x << ", " << y << ")" << endl; } }; int main() { Point p(3, 4), q(1, 2); Point r = p + q; r.show(); // (4, 6) return 0; }

  1. Q4

    Can we use object-oriented concepts with structures instead of classes? Justify your answer.

    Worked answer

    Yes. In C++ a struct is a class with public members by default. It may contain data members, member functions, constructors, access specifiers, and base classes, and it may take part in inheritance and virtual functions. All OOP concepts therefore work with structures.

    Two differences remain: members of a struct are public unless specified otherwise while members of a class are private by default, and inheritance from a struct is public by default while inheritance from a class is private by default.

    struct Point { int x, y; // public by default Point(int a, int b) : x(a), y(b) {} int sum() const { return x + y; } };

  2. Q5

    When are default arguments used? Explain with an example.

    Worked answer

    Default arguments are used when a caller may reasonably omit trailing arguments; the compiler then supplies the listed value. Defaults must be given from the rightmost parameter leftwards, so every parameter after a defaulted one also has a default. Give defaults in the declaration, not again in the definition, and avoid combining them with overlapping overloads that make a call ambiguous.

    void print(int times = 3, char mark = '*'); // declaration void print(int times, char mark) { // no defaults here for (int i = 0; i < times; ++i) cout << mark; cout << endl; } print(); // *** print(2, '#'); // ##

  3. Q6

    What is the purpose of static data members and static functions? Illustrate with an example.

    Worked answer

    A static data member has exactly one copy shared by every object of the class instead of one copy per object. It is useful for class-wide facts such as a count of live objects. A static member function belongs to the class, is called with Class::function(), has no this pointer, and can directly access only static members.

    class Counter { static int count; // one copy for the whole class public: Counter() { ++count; } ~Counter() { --count; } static int live() { return count; } // no this pointer }; int Counter::count = 0; // definition Counter a, b; cout << Counter::live() << endl; // 2
    [5]
  4. Q7

    Differentiate between aggregation and inheritance. Why is a virtual base class needed?

    Worked answer

    Aggregation is a has-a relationship: one class holds an object of another class, and the contained object can exist on its own. A Teacher may hold a Course. Inheritance is an is-a relationship: the derived class is a specialised form of the base and inherits its interface and implementation.

    A virtual base class is needed in a diamond hierarchy. Without it, a class derived from two siblings inherits two separate copies of the common base, which makes member access ambiguous and duplicates data. Declaring the inheritance virtual keeps one shared base subobject.

    class A { public: int x; }; class B : virtual public A {}; class C : virtual public A {}; class D : public B, public C { public: void set() { x = 5; } // one shared A::x, not two };

  5. Q8

    Define a stream. How do you read text from a file? Explain.

    Worked answer

    A stream is an abstraction of a sequence of bytes moving between a program and a source or destination. It carries formatting state and a position, so the same operations work for the console, a string, or a file.

    To read text: include <fstream>, create an ifstream, open the file, test that it opened, read with >> for whitespace-separated values or getline() for whole lines, and close the stream.

    #include <fstream> #include <iostream> #include <string> using namespace std; int main() { ifstream in("notes.txt"); if (!in) { cerr << "Open failed" << endl; return 1; } string line; while (getline(in, line)) cout << line << endl; in.close(); return 0; }

  6. Q9

    Explain the features of object-oriented programming.

    Worked answer
    • Encapsulation: data and the functions that operate on it are bound in a class, and access specifiers protect the representation.
    • Abstraction: the class shows only what callers need, hiding how it is implemented.
    • Inheritance: new classes reuse and extend proven base classes instead of copying code.
    • Polymorphism: the same message produces different behaviour: overloaded functions and templates at compile time, virtual functions at run time.
    • Dynamic binding: a virtual call is bound to the actual object's override at run time.
    • Reusability and maintainability: objects communicate through interfaces, so one tested class can be used in many programs.

    Define a namespace. List any two manipulators and their uses.

  8. Q11

    Why is a friend class needed? How can we define a member function outside the class?

    Worked answer

    A friend class is needed when two classes are so tightly coupled that one must reach into the other's private state, for example a linked list and its node helper. A declaration friend class Helper; grants that access without exposing the data to every other class. Friendship is not inherited and is not symmetric.

    To define a member function outside the class, declare it in the class body and define it with the scope resolution operator: ReturnType ClassName::function(parameters) { ... }.

    class Box { int len; public: Box(int l); int value() const; }; Box::Box(int l) : len(l) {} // outside the class int Box::value() const { return len; }

  9. Q12

    Explain the use of a pure virtual function with an example.

    Worked answer

    A pure virtual function declares an operation that every derived class must provide but that has no meaningful base implementation. It is written virtual returnType f() = 0;. A class containing one is abstract and cannot be instantiated; it acts as an interface. A call through a base pointer still reaches the derived override, giving run-time polymorphism.

    class Shape { public: virtual double area() const = 0; // must be overridden virtual ~Shape() {} }; class Rectangle : public Shape { double w, h; public: Rectangle(double w, double h) : w(w), h(h) {} double area() const override { return w * h; } }; Shape* s = new Rectangle(3, 4); cout << s->area(); // 12 delete s;

  1. Q1

    What is a constructor? Explain its types with suitable examples. How is a constructor called in a derived class in C++?

    Worked answer

    A constructor is a member function with the class name and no return type. It runs automatically when an object is created and initialises that object. Types are the default constructor (no arguments), the parameterised constructor (takes initial values), the copy constructor (builds from another object), and the move constructor (takes resources from a temporary).

    class Box { int len; public: Box() : len(0) {} // default Box(int l) : len(l) {} // parameterised Box(const Box& b) : len(b.len) {} // copy };

    In a derived class the base constructor runs first. Select it in the member initialiser list with Derived(...) : Base(args) { ... }. If no base call is written, the base default constructor is used; if none exists, the code will not compile. After the base comes each member's constructor, then the derived constructor body. Destructors run in the reverse order.

    class Base { public: Base(int x) { cout << "Base " << x << endl; } }; class Derived : public Base { public: Derived() : Base(7) { cout << "Derived" << endl; } // calls Base(7) first };

  2. Q2

    What is polymorphism in object-oriented programming? Implement a class Employee with a virtual function CalculateSalary() that returns the salary of the employee. Create two derived classes HourlyEmployee and SalariedEmployee. Override CalculateSalary() in both derived classes to calculate the salary of an hourly employee and a salaried employee respectively. Write a program that creates objects of both derived classes and calls CalculateSalary() for each.

    Worked answer

    Polymorphism means "many forms": one interface produces different behaviour. Compile-time polymorphism comes from overloading and templates. Run-time polymorphism comes from a virtual function called through a base pointer or reference; the override chosen depends on the actual object.

    Here Employee::CalculateSalary() is virtual. Each derived class overrides it, and both objects are called through Employee*, so each call reaches the right salary formula.

    #include <iostream> #include <string> using namespace std; class Employee { string name; public: Employee(const string& n) : name(n) {} virtual double CalculateSalary() const { return 0.0; } virtual ~Employee() {} void print() const { cout << name << ": " << CalculateSalary() << endl; } }; class HourlyEmployee : public Employee { int hours; double rate; public: HourlyEmployee(const string& n, int h, double r) : Employee(n), hours(h), rate(r) {} double CalculateSalary() const override { return hours * rate; } }; class SalariedEmployee : public Employee { double salary; public: SalariedEmployee(const string& n, double s) : Employee(n), salary(s) {} double CalculateSalary() const override { return salary; } }; int main() { HourlyEmployee hourly("Hari", 40, 250); SalariedEmployee salaried("Sita", 30000); Employee* e1 = &hourly; Employee* e2 = &salaried; e1->print(); // Hari: 10000 e2->print(); // Sita: 30000 return 0; }

  3. Q3

    What is operator overloading? Write a complete C++ program to overload the + operator to add two objects of class Time.

    Worked answer

    Operator overloading gives a special meaning to an existing operator for a user-defined type. It is written as a member or friend function named operator+. It cannot change the operator's precedence, associativity or number of operands, and at least one operand must be a user-defined type.

    The member operator+ below converts each Time to total seconds, adds them, and returns a new Time with the normalised hours, minutes and seconds. The operands are taken by const reference and are unchanged.

    #include <iostream> #include <iomanip> using namespace std; class Time { int hours, minutes, seconds; public: Time(int h = 0, int m = 0, int s = 0) : hours(h), minutes(m), seconds(s) {} Time operator+(const Time& other) const { int a = hours * 3600 + minutes * 60 + seconds; int b = other.hours * 3600 + other.minutes * 60 + other.seconds; int t = a + b; return Time(t / 3600, (t / 60) % 60, t % 60); } void show() const { cout << setfill('0') << setw(2) << hours << ':' << setw(2) << minutes << ':' << setw(2) << seconds << setfill(' ') << endl; } }; int main() { Time t1(1, 30, 0), t2(0, 45, 30); Time total = t1 + t2; cout << "t1 = "; t1.show(); cout << "t2 = "; t2.show(); cout << "sum = "; total.show(); // 02:15:30 return 0; }

Section B · Short answer questions Attempt any eight

  1. Q4

    What is the difference between public, private, and protected inheritance in C++?

    Worked answer

    The access specifier on an inheritance declaration sets the minimum access of inherited members in the derived class:

    • Public inheritance: public base members stay public and protected members stay protected. This models is-a and is the usual form.
    • Private inheritance: both public and protected base members become private in the derived class. Outside code cannot use the base interface.
    • Protected inheritance: public base members become protected and protected members stay protected. Outside code again cannot use the base interface, but further derived classes can.

    Private base members are never directly accessible in any of the three forms; they remain accessible only through the base's own public or protected functions.

    [5]
  2. Q5

    What is exception handling? Explain types of exception handling and illustrate with a suitable example.

    Worked answer

    Exception handling is the try / throw / catch mechanism for dealing with errors without mixing error checks into normal logic. The guarded code sits in try; throw raises an exception value; the first matching catch handles it.

    Types: standard exceptions thrown by the library such as std::bad_alloc and std::out_of_range; user-defined exceptions, either a thrown value or a class derived from std::exception; and a catch-all catch (...) that handles any remaining exception. Stack unwinding destroys automatic objects before the handler runs.

    #include <iostream> #include <stdexcept> using namespace std; int main() { try { int n = -1; if (n < 0) throw runtime_error("negative value"); cout << n; } catch (const runtime_error& e) { cerr << "Error: " << e.what() << endl; } catch (...) { cerr << "Unknown error" << endl; } return 0; }
    [5]
  3. Q6

    What is a friend function? Write a program to add private members of two different classes using a friend function.

    Worked answer

    A friend function is a non-member function declared with the friend keyword inside a class. Friendship lets it access that class's private and protected members. It is useful when an operation naturally involves two classes, as addition here does. Friendship is not inherited and works one way only.

    #include <iostream> using namespace std; class B; // forward declaration class A { int a; public: A(int x) : a(x) {} friend int add(const A&, const B&); }; class B { int b; public: B(int x) : b(x) {} friend int add(const A&, const B&); }; int add(const A& x, const B& y) { return x.a + y.b; // private in both classes } int main() { A x(10); B y(20); cout << add(x, y) << endl; // 30 return 0; }

  4. Q7

    Write a program to demonstrate returning an object from a function in C++.

    Worked answer

    A function may return a class object by value. The return expression constructs the object; in modern C++ copy elision or a move avoids a separate copy. The caller receives an independent object with its own copy of the data.

    #include <iostream> using namespace std; class Number { int n; public: Number(int v = 0) : n(v) {} void show() const { cout << n << endl; } }; Number makeNumber(int v) { // returns an object return Number(v); } int main() { Number x = makeNumber(7); x.show(); // 7 return 0; }

  5. Q8

    How is the this pointer used to resolve name conflicts between a local variable and a member variable in C++? Explain with an example.

    Worked answer

    this is an implicit pointer available inside non-static member functions. It points to the object on which the function was called. When a parameter or local variable has the same name as a data member, it hides that member. Writing this->x forces the member to be used, while plain x means the local variable.

    class Box { int len; public: void set(int len) { this->len = len; // member = parameter } int value() const { return len; } }; Box b; b.set(9); // b.value() is 9

  6. Q9

    Write a program to read and write values using objects with file handling.

    Worked answer

    Put the file logic inside the object. One member writes the object's fields to an ofstream; another reads them from an ifstream and reports whether the read succeeded. The caller opens the streams, uses these members, and closes the streams.

    #include <iostream> #include <fstream> using namespace std; class Record { int id; char name[30]; public: void readFromUser() { cout << "id and name: "; cin >> id >> name; } void writeToFile(ofstream& out) const { out << id << ' ' << name << '\n'; } bool readFromFile(ifstream& in) { return static_cast<bool>(in >> id >> name); } void show() const { cout << id << ' ' << name << endl; } }; int main() { Record r; r.readFromUser(); ofstream out("records.txt"); r.writeToFile(out); out.close(); ifstream in("records.txt"); Record loaded; while (loaded.readFromFile(in)) loaded.show(); in.close(); return 0; }

  7. Q10

    What is a class template in C++? Write a C++ program containing a function template that determines the greater number between two integers and between two floating-point values.

    Worked answer

    A class template is a blueprint from which the compiler generates classes for specific types, for example template <typename T> class Stack. It keeps one implementation for many types and is type-safe. A function template does the same for functions.

    #include <iostream> using namespace std; template <typename T> T greaterOf(T a, T b) { return (a > b) ? a : b; } int main() { cout << greaterOf(7, 3) << endl; // int: 7 cout << greaterOf(2.5, 4.75) << endl; // double: 4.75 return 0; }

  8. Q11

    Differentiate between function overloading and function overriding in C++.

    Worked answer
    • Overloading: same function name, different parameter list, normally in the same scope. Resolved at compile time. Return type alone cannot distinguish overloads.
    • Overriding: same name and signature, but in a derived class, with a virtual function in the base. Resolved at run time through a base pointer or reference.

    Overloading gives compile-time (static) polymorphism; overriding gives run-time (dynamic) polymorphism.

  9. Q12

    Illustrate the use of a static variable with a simple program.

    Worked answer

    A local static variable is created once, on the first call, and keeps its value between calls. Here it counts how many times calls() has run. A static data member does the same job at class level, with one copy shared by every object.

    #include <iostream> using namespace std; int calls() { static int count = 0; // created once, not on each call return ++count; } int main() { cout << calls() << " " << calls() << " " << calls() << endl; return 0; // 1 2 3 }
