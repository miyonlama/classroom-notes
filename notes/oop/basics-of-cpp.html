Basics of C++ Programming

Before the class exists, C++ gives us the raw material: tokens, types, I/O, memory, and functions. Units 2.1 to 2.3 of the syllabus are the foundation the later OOP units stand on.

Unit prose and C++ examples are written from the syllabus and standard C++.

Recall cues

  1. What does the preprocessor do before the compiler sees a source file?
  2. How do cin, cout, cascading operators, and manipulators like endl, setw, and setprecision fit together?
  3. What does new and delete change about memory, and when should a program manage it manually?
  4. How do overloading, inline, default arguments, pass by reference, and return by reference change function behaviour?
  5. How do pointers declare, point to, and walk memory, and what do pointers-to-arrays and pointers-to-functions mean?

Part 1 · C++ foundations ★★★

Units 2.1, 2.2, and 2.3 of the syllabus.

1. Program structure, tokens, and types ★★★ EXAM 1

A C++ translation unit starts with the preprocessor, then declarations, then functions. Tokens are the smallest units: keywords, identifiers, literals, operators, and punctuators.

2. Input, output, and manipulators ★★ EXAM 2

cin and cout are streams. Cascading operators let you write `cin >> a >> b`; endl, setw, and setprecision control line breaks and numeric formatting.

3. new, delete, and memory ★★ EXAM 1

new and delete allocate and free heap memory; a class owning pointers must manage ownership carefully.

Part 2 · Functions ★★

Unit 2.2 of the syllabus.

1. Function overloading ★★ EXAM 2

Overloading lets one name mean many signatures; the compiler picks the matching function at compile time.

2. Inline functions ★★ EXAM 2

Inline hints the compiler to place a function's code directly inside its call sites.

3. Default arguments ★★ EXAM 2

Default arguments fill missing parameters so callers may omit trailing ones.

4. Pass by reference ★★ EXAM 1

References pass or return values without copying.

Part 3 · Pointers ★★

Unit 2.3 of the syllabus.

1. Pointer declaration, arithmetic, and arrays ★★ EXAM 2

A pointer holds an address; arithmetic moves through the pointed type; arrays are contiguous memory, so a pointer can walk them.

2. Pointers and functions ★★ EXAM 2

A function pointer names a function as data; useful for callbacks and for passing behaviour around.

<#include <iostream> void swap(int & a, int & b) { int t = a; a = b; b = t; } int main() { int x = 3; int y = 5; swap(x, y); std::cout << x << " " << y << std::endl; return 0; }
