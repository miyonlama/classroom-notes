File and Streams

The C++ stream library separates file input from file output. Binary mode transfers raw bytes; text mode performs character translation. The file pointer position is managed by seek operations.

Part 1 · Stream Class Hierarchy ★★★

Unit 8.1 of the syllabus.

1. Stream class hierarchy EXAM 6

The stream hierarchy derives from base classes for input and output. `ifstream` handles file input, `ofstream` handles file output, and `fstream` handles both. Each uses a stream buffer for character transfer.

2. Reading and writing file pointers

The get pointer marks the next byte to read; the put pointer marks the next byte to write. `seekg` repositions the get pointer, and `seekp` repositions the put pointer.

#include <iostream> #include <fstream> int main() { std::ofstream out("data.txt"); out << 10 << " " << 20 << std::endl; out.close(); std::ifstream in("data.txt"); int value; while (in >> value) { std::cout << value << std::endl; } in.close(); return 0; }

3. Text files

Text files store human-readable characters. Formatted operators (>> and <<) read and write typed values with automatic conversion. Each insertion ends with a newline when std::endl is used.

4. End-of-file detection

A read reaches end of file when no further value is available. The extraction expression itself becomes false in that state, so a while loop using it stops naturally. The eof() member reports the EOF flag.

Part 2 · Binary Files and Random Access ★★★

Unit 8.2 of the syllabus.

1. Binary files

Binary files store raw bytes without text translation. Passing `ios::binary` to the stream constructor disables newline conversion and preserves the in-memory representation of data.

#include <iostream> #include <fstream> int main() { std::ofstream out("data.bin", std::ios::binary); int value = 65; out.write(reinterpret_cast<const char*>(&value), sizeof(value)); out.close(); return 0; }

2. Reading and writing objects

The write() member copies the raw bytes of an object to a file. The read() member restores those bytes into an object. Both take a char pointer and a byte count.

#include <iostream> #include <fstream> struct Record { int id; double score; }; int main() { Record r = {1, 3.5}; std::ofstream out("records.bin", std::ios::binary); out.write(reinterpret_cast<const char*>(&r), sizeof(r)); out.close(); std::ifstream in("records.bin", std::ios::binary); Record copy; in.read(reinterpret_cast<char*>(&copy), sizeof(copy)); std::cout << copy.id << " " << copy.score << std::endl; in.close(); return 0; }

3. Random file access with seekg

The seekg member repositions the get pointer by a byte offset. The offset can be measured from the start (`ios::beg`), the current position (`ios::cur`), or the end (`ios::end`). Fixed-size records let a record be read directly by multiplying its size by its index.

#include <iostream> #include <fstream> struct Record { int id; double score; }; int main() { std::ofstream out("records.bin", std::ios::binary); for (int i = 0; i < 3; i++) { Record r = {i, i * 1.5}; out.write(reinterpret_cast<const char*>(&r), sizeof(r)); } out.close(); std::ifstream in("records.bin", std::ios::binary); Record r; in.seekg(sizeof(Record) * 1, std::ios::beg); in.read(reinterpret_cast<char*>(&r), sizeof(r)); std::cout << "Record 1: id=" << r.id << ", score=" << r.score << std::endl; in.close(); return 0; }
