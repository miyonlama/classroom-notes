Operator Overloading

Operator overloading gives ordinary C++ operators a meaning for user-defined types. One operator, many behaviours, decided by the class that overloads it.

Unit prose and C++ examples are written from the syllabus and standard C++.

Recall cues

  1. Which operators can be overloaded, and what behaviour does the compiler forbid?
  2. How do unary pre-increment, post-increment, and negation differ?
  3. How do binary plus, comparison, and string concatenation overload?
  4. How do basic-to-user-defined, user-defined-to-basic, and user-defined-to-user-defined conversions work?

Part 1 · Operator Overloading Fundamentals ★★

Unit 4.1 of the syllabus.

1. Operator overloading: fundamentals, restrictions, and member operator functions ★★ EXAM 6

Operator overloading lets a member function or a friend function carry out an operation the built-in operator has no meaning for. operator new, new[], delete, delete[], and operator= can be overloaded. Restrictions: no new operator symbols; arity, precedence, and associativity are fixed; at least one operand must be a class or enum type; ., .*, ::, ?:, sizeof, and typeid cannot be overloaded.

Part 2 · Unary Operators ★★

Unit 4.2 of the syllabus.

2. Unary operators: Pre-increment, Post-increment, and Negation ★★

Unary operators take one operand. Pre-increment (++obj) returns the updated object; post-increment (obj++) returns the old value; negation (operator-) negates the value.

Part 3 · Binary Operators and String Concatenation ★★

Unit 4.3 of the syllabus.

3. Binary plus, comparison, and String Concatenation ★★

Binary operators take two operands. Plus can add numbers or concatenate strings; comparison operators can compare objects field by field.

Part 4 · Conversions ★

Unit 4.4 of the syllabus.

1. Basic-to-user-defined conversion

A basic type converts into a user-defined type through a converting (non-explicit) constructor: a constructor callable with a single argument of the basic type. C++ uses it automatically when a value of the basic type is supplied where the class is expected. Mark it explicit if implicit conversion would be surprising.

2. User-defined-to-basic conversion

A user-defined type converts into a basic type through a conversion operator, such as operator int() const, declared in the class. An explicit constructor does not convert.

3. User-defined-to-user-defined conversion

A user-defined type converts into another user-defined type through a conversion operator in the source class returning the target type, or through a converting constructor in the target class.

#include <iostream> #include <string> class Number { int value; public: Number(int v) : value(v) {} // Binary overload: operator+ Number operator+(const Number & other) const { return Number(value + other.value); } // Comparison overload: operator== bool operator==(const Number & other) const { return value == other.value; } // Unary overload: operator++ (pre-increment) Number & operator++() { ++value; return *this; } // Unary overload: operator++ (post-increment) Number operator++(int) { Number tmp = *this; ++value; return tmp; } }; std::string concatenate(const std::string & a, const std::string & b) { return a + b; } int main() { Number x(2); Number y(3); Number sum = x + y; Number next = ++x; Number old = y++; return 0; }
