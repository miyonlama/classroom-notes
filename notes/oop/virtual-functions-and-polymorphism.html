Virtual Function, Polymorphism, and other C++ Features

Virtual functions let a base class method be overridden, and a base pointer routes the call to the right derived object. That is dynamic polymorphism in C++.

Part 1 · Static and Dynamic Polymorphism ★★★

Unit 6.1 of the syllabus.

1. Virtual functions and dynamic polymorphism ★★ EXAM 5

Polymorphism gives one interface, many implementations. Static polymorphism binds at compile time through overloading; dynamic polymorphism binds at runtime through virtual functions reached by a pointer to the base class.

Part 2 · Implementing Dynamic Polymorphism ★★

Unit 6.1 of the syllabus.

2. Implementing dynamic polymorphism through a base pointer

A base class pointer can hold a derived object, and the virtual call resolves to the derived override at runtime. The implementation repeats the base signature in the derived class.

Part 3 · Pure Virtual Functions and Abstract Class ★

Unit 6.1 of the syllabus.

3. Pure Virtual Functions

A Pure Virtual Function is marked = 0; it need not have a body, though an out-of-class body can still be supplied. A class holding a Pure Virtual Function is an Abstract class and cannot be instantiated.

4. Abstract class and Virtual Destructor

A derived class stays abstract until it overrides every pure virtual function; a class with a Pure Virtual Function cannot be instantiated. A Virtual Destructor in the base class releases derived state when deleting through a base pointer.

#include <iostream> class Employee { public: virtual void calculatePay() { std::cout << "Employee pay" << std::endl; } virtual ~Employee() {} }; class Typist : public Employee { public: void calculatePay() { std::cout << "Typist pay" << std::endl; } }; int main() { Employee *e = new Typist(); e->calculatePay(); delete e; }
