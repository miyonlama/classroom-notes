Class and Objects

A class is a blueprint and an object is a concrete instance built from it. This unit turns that distinction into C++ code: members, access specifiers, constructors, destructors, static members, friends, and the this pointer.

Unit prose and C++ examples are written from the syllabus and standard C++.

Recall cues

  1. What is the difference between a class and an object, and how do access specifiers scope state?
  2. What do default, parameterized, copy, and default copy constructors, plus the destructor, cover?
  3. How do objects passed as arguments, returned objects, static data members, and static functions behave?
  4. What is a Friend Function, Friend Class, copy initialization, and what does the this pointer bind to?

Part 1 · Classes and Objects ★★

Unit 3.1 of the syllabus.

1. Classes, objects, and encapsulation via member functions ★★ EXAM 2

A class is a blueprint and an object is a concrete instance built from it. Encapsulation bundles state and behaviour into one unit and gates access through access specifiers: private, public, and protected. Members sit on the instance; the class owns the shape.

Part 2 · Constructors and Destructors ★★

Unit 3.2 of the syllabus.

2. Constructors and destructors ★★ EXAM 5

A class can define a default constructor, a parameterized constructor, a Copy Constructor, a default copy constructor, and a destructor. The Copy Constructor takes an existing object and copies its state into the new object, so the new instance starts as a faithful duplicate.

Part 3 · Objects as Arguments, Returns, and Static Members ★★

Unit 3.3 of the syllabus.

1. Objects as function arguments and return values

Objects can travel as arguments and come back as return values. Large objects travel safer by const reference, and the return value may move or copy depending on the compiler.

2. Static data members and static functions

Static data members belong to the class rather than any instance, and static functions answer questions about the class without an object.

Part 4 · Friends, Copy Initialization, and the this pointer ★★

Unit 3.4 of the syllabus.

1. Friend Function and Friend Class ★★ EXAM 5

A Friend Function or Friend Class is granted access to private and protected members without becoming an owner. The this pointer refers to the specific object a member function was called on.

2. Copy Initialization and the this pointer

Copy initialization builds an object through a constructor or a copy constructor, and the this pointer always binds to the object whose member function is running.

<#include <iostream> <#include <string> class Employee { std::string eid; std::string ename; int salary; public: Employee(std::string id, std::string name, int pay) : eid(id), ename(name), salary(pay) {} // Copy Constructor Employee(const Employee & other) : eid(other.eid), ename(other.ename), salary(other.salary) {} void giveRaise(int percent) { this->salary = salary + (salary * percent / 100); } void display() { std::cout << eid << " " << ename << " " << salary << std::endl; } }; int main() { Employee e("E01", "Ram", 50000); Employee copy(e); copy.giveRaise(10); copy.display(); return 0; }
