Function Templates and Exception Handling

Function templates provide generic functions that operate on multiple types. Exception handling lets a program recover from runtime errors through try, throw, and catch.

Part 1 · Function Templates ★★★

Unit 7.1 of the syllabus.

1. Function templates EXAM 3

Function templates enable a function to accept arguments of multiple types. The template parameter is deduced from the argument types or explicitly specified at the call.

#include <iostream> template <typename T> T maximum(T a, T b) { return (a > b) ? a : b; } int main() { std::cout << maximum(3, 7) << std::endl; std::cout << maximum(3.5, 7.2) << std::endl; std::cout << maximum(char('a'), char('b')) << std::endl; }

2. Class Template

A Class Template defines a generic class whose members use the template type parameter. It supports containers that hold values of any chosen type.

#include <iostream> template <typename T> class Box { T content; public: void set(T c) { content = c; } T get() { return content; } }; int main() { Box<int> intBox; intBox.set(123); std::cout << intBox.get() << std::endl; Box<double> doubleBox; doubleBox.set(3.5); std::cout << doubleBox.get() << std::endl; }

3. Templates and inheritance

A derived class can inherit from a base template class, with the template argument fixed in the derivation clause. A virtual function in the base reaches the derived override through a base pointer.

#include <iostream> template <typename T> class Base { public: virtual void print() { std::cout << "Base" << std::endl; } virtual ~Base() {} }; template <typename T> class Derived : public Base<T> { public: void print() { std::cout << "Derived" << std::endl; } }; int main() { Derived<int> d; Base<int> *b = &d; b->print(); }

4. Rules for templates

Template arguments must be consistent with the parameter list. Default template arguments are allowed, and an explicit specialization can replace the generic definition for a specific type.

Part 2 · Exception Handling ★★★

Unit 7.2 of the syllabus.

1. Exception mechanism: try, throw, catch EXAM 6

An exception is thrown at runtime with throw and caught by a handler introduced with catch. A try block guards the statements that may raise the exception.

#include <iostream> #include <stdexcept> double divide(double a, double b) { if (b == 0) throw std::runtime_error("Division by zero"); return a / b; } int main() { try { std::cout << divide(10, 0) << std::endl; } catch (const std::runtime_error& e) { std::cout << "Caught: " << e.what() << std::endl; } catch (...) { std::cout << "Caught unknown exception" << std::endl; } return 0; }

2. Multiple catch

Catch handlers are examined in order. The first handler that matches the thrown type runs. Listing specific types before the catch-all handler gives precise recovery for each error.

#include <iostream> int main() { try { throw 42; } catch (int i) { std::cout << "Integer: " << i << std::endl; } catch (double d) { std::cout << "Double: " << d << std::endl; } catch (...) { std::cout << "Unknown exception" << std::endl; } return 0; }

3. Catching all exceptions

A handler written as catch (...) matches every exception type. Place it last so that specific handlers keep priority and no exception escapes unhandled.

4. Uses of exception handling

Exception handling separates error detection from error recovery. It is used for invalid input, failed resource allocation, division by zero, and file or network errors.
