Define spanning tree and minimum spanning tree with a suitable example. Use Kruskal’s algorithm to find the minimum spanning tree of the given graph.

Frequency: 2078 (Q3) · Marks: 10

A spanning tree of a connected graph is a subtree containing every vertex and n − 1 edges for n vertices; it is acyclic and connected. A minimum spanning tree (MST) is a spanning tree of least total edge weight.

Kruskal’s algorithm sorts edges by weight and adds an edge whenever it joins two different components, skipping edges that would close a cycle.

For the figure, the edges in increasing order are: ab 7, eg 8, ce 10, dg 11, fg 13, df 15, bf 17, ac 18, cd 19. Select ab 7, eg 8, ce 10, dg 11, fg 13; df 15 is skipped because d and f are already connected. Add bf 17 to join the last component. The MST is {ab, eg, ce, dg, fg, bf} with total weight 7 + 8 + 10 + 11 + 13 + 17 = 66.

What is a graph? Explain a simple graph and a pseudograph with examples.

Frequency: 2078 (Q11) · Marks: 5

A graph G = (V, E) consists of a set V of vertices and a set E of edges joining pairs of vertices. Edges may be directed or undirected.

A simple graph is undirected with no loops and no parallel edges: each edge joins two distinct vertices and at most one edge joins a given pair. Example: the triangle with V = {a, b, c}, E = {ab, bc, ca}.

A pseudograph allows loops (an edge from a vertex to itself) and multiple edges between the same pair. Example: vertices {a, b} with a loop at a and two distinct edges joining a and b. A multigraph allows parallel edges but no loops.

What is an Euler path? Compare it with a Hamiltonian path.

Frequency: 2078 (Q12) · Marks: 5

An Euler path is a trail that uses every edge exactly once; vertices may repeat. An Euler circuit is an Euler path that starts and ends at the same vertex.

A Hamiltonian path visits every vertex exactly once; edges between those vertices may be unused. A Hamiltonian cycle returns to the start.

Example: a square a–b–c–d–a with diagonal a–c. Degrees of a and c are 3 (odd), b and d are 2; hence an Euler path exists from a to c, for example a–b–c–d–a–c. The boundary a–b–c–d–a is a Hamiltonian cycle that omits the diagonal.

The tests are different in kind: Euler depends on edge degrees; Hamiltonicity has no simple degree criterion.

State necessary and sufficient conditions for a graph to have an Euler path and for it to have an Euler circuit. Find gcd(12, 18) using the extended Euclidean algorithm.

Frequency: 2079 (Q3) · Marks: 4+6

A connected undirected graph has an Euler circuit iff every vertex has even degree. It has an Euler path that is not a circuit iff exactly two vertices have odd degree; the path starts at one and ends at the other. With more than two odd vertices no Euler path exists.

Extended Euclidean algorithm for gcd(12, 18): 18 = 1·12 + 6, then 12 = 2·6 + 0, so the last nonzero remainder is gcd(12, 18) = 6. Back-substituting, 6 = 18 − 1·12, giving the Bezout coefficients 1 for 18 and −1 for 12.

Write Dijkstra’s algorithm to find the shortest path between two nodes in a weighted graph (no negative weights).

Frequency: 2079 (Q12) · Marks: 5

Dijkstra’s algorithm solves the single-source shortest-path problem when all edge weights are nonnegative.

  1. Set d(source) = 0 and d(v) = ∞ for all other vertices; mark none as settled.
  2. Repeatedly pick an unsettled vertex u of least tentative distance d(u) and mark it settled.
  3. For each neighbour v of u with weight w, relax: if d(u) + w < d(v), set d(v) = d(u) + w and record u as the predecessor of v.
  4. Stop when all vertices are settled (or when the target is settled) and reconstruct the path backwards through predecessors.

Nonnegative weights are essential: relaxing an edge into an already settled vertex could otherwise improve it later. With a binary heap the running time is O((|V| + |E|) log |V|).

Describe preorder, inorder, and postorder traversals of a tree with an example.

Frequency: 2080.1 (Q4) · Marks: 5

Traversal visits every node of a rooted tree in a fixed order: root, left subtree, right subtree.

  • Preorder: visit the root, then the left subtree, then the right subtree.
  • Inorder: visit the left subtree, the root, then the right subtree.
  • Postorder: visit the left subtree, the right subtree, then the root.

Example: root A with children B and C, and B with children D and E. Preorder: A, B, D, E, C. Inorder: D, B, E, A, C. Postorder: D, E, B, C, A. Preorder is used to copy a tree and to print prefix expressions; postorder gives postfix expressions.

Explain the incidence-matrix representation of a graph with an example.

Frequency: 2080.1 (Q11) · Marks: 5

An incidence matrix of an undirected graph has one row per vertex and one column per edge, with entry 1 when the vertex is an endpoint of that edge and 0 otherwise (2 for a loop, under the usual convention).

Example: V = {a, b, c}, edges e₁ = ab, e₂ = bc, e₃ = ca. Ordering rows a, b, c and columns e₁, e₂, e₃ gives:

a: 1 0 1; b: 1 1 0; c: 0 1 1.

Each column sums to 2 and each row sums to the degree of its vertex. Incidence matrices suit edge-focused algorithms; adjacency matrices suit quick tests of whether two vertices are joined.

Define tree traversal. Explain preorder traversal with an example.

Frequency: 2080.1 (Q12) · Marks: 5

Tree traversal is a systematic visit of every node exactly once. In preorder the root is processed before its subtrees: visit the root, then traverse the left subtree in preorder, then the right subtree in preorder.

Example: root r has left child s and right child t; s has child u. The preorder visit is r, s, u, t. The root r comes first and each descendant follows its parent before that parent’s siblings.

Preorder is natural for copying a tree: the first node of a subtree is always its root, so the sequence can rebuild the original structure. It also produces prefix (Polish) notation for expression trees.

Differentiate between a graph and a tree. State necessary conditions for two graphs to be isomorphic and give an example.

Frequency: 2080.2 (Q3) · Marks: 2+8

A graph is any collection of vertices and edges; it may contain cycles and may be disconnected. A tree is a connected graph with no cycles. Equivalently, a tree on n vertices has exactly n − 1 edges, and there is a unique path between any two of its vertices.

Two graphs are isomorphic when there is a bijection f between their vertex sets such that uv is an edge exactly when f(u)f(v) is an edge. Necessary conditions are equal vertex and edge counts and the same multiset of degrees; these are not sufficient in general.

Example: the 4-cycle a–b–c–d–a and the square 1–2–3–4–1 are isomorphic under a↦1, b↦2, c↦3, d↦4.

Explain how Kruskal’s algorithm works and illustrate with an example.

Frequency: 2080.2 (Q5) · Marks: 5

Kruskal’s algorithm builds a minimum spanning tree by greedily adding the cheapest edge that does not create a cycle.

  1. Sort all edges by nondecreasing weight.
  2. Start with n isolated components, one per vertex.
  3. Scan the sorted edges and add an edge iff its endpoints lie in different components; merge those components.
  4. Stop after n − 1 edges have been chosen.

Example: vertices {1, 2, 3, 4} with edges 1–2 (1), 2–3 (2), 3–4 (3), 1–4 (4), 1–3 (5). Choose 1–2, 2–3, 3–4; edge 1–4 is skipped because 1 and 4 are already connected. The MST has total weight 1 + 2 + 3 = 6.

Cycle detection is efficiently done with a union–find structure; sorting dominates at O(|E| log |E|).

Write Dijkstra’s algorithm to find the shortest path from a source node to a goal node.

Frequency: 2080.2 (Q10) · Marks: 5

Initialise d(source) = 0, all other distances to ∞, and keep predecessors empty. At each step extract the unsettled vertex u with smallest d(u). For every outgoing edge (u, v) of weight w ≥ 0, relax: if d(u) + w < d(v), update d(v) and set pred(v) = u.

Mark u settled after extraction, because with nonnegative weights no later route through another vertex can reduce d(u). Stop as soon as the goal node is extracted: its distance is final at that moment. Follow predecessors from the goal back to the source and reverse the list to obtain the path.

A priority queue gives O((|V| + |E|) log |V|). With negative edges the algorithm can fail; use Bellman–Ford instead.

Define graph isomorphism with an example. Using Kruskal’s algorithm, generate the minimum spanning tree for the graph shown in the question image.

Frequency: 2081 (Q1) · Marks: 5+5

Graphs G = (V, E) and H = (W, F) are isomorphic if a bijection f : V → W exists with uv ∈ E exactly when f(u)f(v) ∈ F. Isomorphic graphs are the same abstract graph drawn differently.

Kruskal on the figure. Edges by weight: 1–2 (1), 3–6 (2), 4–5 (6), 1–3 (9), 5–6 (9), 2–3 (10), 3–4 (11), 1–6 (14), 2–4 (15). Select 1–2, 3–6, 4–5, 1–3 and 5–6. After these five edges all six vertices are connected; later edges would close cycles and are skipped. The minimum spanning tree is {1–2, 3–6, 4–5, 1–3, 5–6} with total weight 1 + 2 + 6 + 9 + 9 = 27.

Explain any two representations of a graph.

Frequency: 2081 (Q8) · Marks: 5

Adjacency matrix. An n × n matrix A with aᵢⱼ = 1 when vertex i is adjacent to j, else 0; symmetric for an undirected graph. Testing adjacency takes O(1), but storing a sparse graph wastes O(n²) space.

Adjacency list. Each vertex keeps a list of its neighbours. Example: for edges ab, ac, bc the lists are a: b, c; b: a, c; c: a, b. This uses O(|V| + |E|) space and makes neighbour iteration fast.

A third option, the incidence matrix, indexes edges against vertices and is convenient when algorithms process edges explicitly.

Define cut vertices and cut edges. How do you determine whether a graph has an Euler path?

Frequency: 2081 (Q11) · Marks: 5

A cut vertex (articulation point) is a vertex whose removal increases the number of connected components. A cut edge (bridge) is an edge whose removal disconnects the graph. In a tree every non-leaf vertex is a cut vertex and every edge is a cut edge.

To decide whether an Euler path exists: first check that all nonzero-degree vertices lie in one connected component. If zero vertices have odd degree, an Euler circuit exists; if exactly two have odd degree, an Euler path exists between them; otherwise none exists. This degree test follows because every time the trail enters a vertex it must leave it, pairing incident edges, except at the two endpoints.

State the necessary and sufficient conditions for an Euler path and an Euler circuit, and give an example.

Frequency: 2082 (Q4) · Marks: 5

For a connected undirected graph: an Euler circuit exists iff every vertex has even degree. An Euler path exists iff the number of odd-degree vertices is 0 or 2; with two odd vertices the path must start at one and end at the other.

Example. The path graph a–b–c has deg(a) = deg(c) = 1 and deg(b) = 2, so exactly two vertices are odd and a–b–c is an Euler path using both edges once. The triangle with vertices x, y, z has all degrees 2, so x–y–z–x is an Euler circuit. A star with three leaves has four odd vertices, so it has no Euler path.

Define a spanning tree and a minimum spanning tree. How do you traverse a tree?

Frequency: 2082 (Q11) · Marks: 2+3

A spanning tree of a connected graph G is a subgraph that contains every vertex of G, is connected, and has no cycles; it therefore has exactly |V| − 1 edges. A minimum spanning tree minimises the sum of edge weights among all spanning trees.

Tree traversal means visiting every node once in a systematic order. Preorder visits root, left subtree, right subtree; inorder visits left subtree, root, right subtree; postorder visits left, right, root; level order visits nodes level by level using a queue. For a root A with children B, C and B with child D, preorder is A, B, D, C and postorder is D, B, C, A.

What is connectivity in a graph? Discuss bipartite and planar graphs.

Frequency: 2082 (Q12) · Marks: 1+4

A graph is connected when there is a path between every pair of vertices; otherwise its maximal connected parts are its components. A directed graph is strongly connected when each vertex can reach every other along directed paths.

A graph is bipartite if its vertices split into two disjoint sets X and Y with every edge joining X to Y. Equivalently, it contains no cycle of odd length. Examples: any path, any even cycle, and the cube graph; the triangle K₃ is not bipartite.

A graph is planar if it can be drawn in the plane with no crossing edges. K₄ is planar; K₃,₃ and K₅ are not. Euler’s formula for a connected planar graph is |V| − |E| + |F| = 2, and a simple planar graph satisfies |E| ≤ 3|V| − 6 for |V| ≥ 3.
