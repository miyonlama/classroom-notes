Part 1 · Mathematical Induction ★★★

Pages 1–4 of the chapter PDF.

1. The principle ★★★ EXAM 4

Induction proves statements of the form ∀n P(n) over the positive integers. It is an extremely important proof technique with two parts:

StepWhat you do
Basis stepShow P(1) is true
Inductive stepShow ∀k(P(k) → P(k + 1)): assume P(k) for an arbitrary k, then prove P(k + 1)

The assumption P(k) is the inductive hypothesis. As a rule of inference:

(P(1) ∧ ∀k(P(k) → P(k + 1))) → ∀n P(n).

2. Proving summation formulae ★★★ EXAM 4

Example: 1 + 2 + … + n = n(n + 1)/2
  1. Basis, P(1): 1 = 1(1 + 1)/2, true.
  2. Assume P(k): 1 + … + k = k(k + 1)/2.
  3. Then 1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2.
  4. That is P(k + 1), so P(n) holds for all positive integers n.
Example: 1 + 3 + 5 + … + (2n − 1) = n²
  1. Basis: P(1) is 1 = 1², true.
  2. Assume P(k) = k². Then add the next odd term: k² + (2(k + 1) − 1) = k² + 2k + 1 = (k + 1)².

Starting at b ≠ 1. Replace the basis step with P(b) and prove P(k) → P(k + 1) for k = b, b + 1, …. The rule becomes P(b) ∧ ∀k(P(k) → P(k + 1)) → ∀n P(n) for n ≥ b.

Example: 1 + 2 + 2² + … + 2ⁿ = 2^(n+1) − 1
  1. Basis P(0): 1 = 2¹ − 1, true.
  2. Assume P(k): sum to 2ᵏ equals 2^(k+1) − 1.
  3. Add 2^(k+1): 2^(k+1) − 1 + 2^(k+1) = 2·2^(k+1) − 1 = 2^(k+2) − 1, which is P(k + 1).

3. Inequalities and divisibility ★★★

Example: n < 2ⁿ for every positive integer
  1. Basis P(1): 1 < 2¹ = 2.
  2. Assume k < 2ᵏ. Then k + 1 < 2ᵏ + 1 ≤ 2ᵏ + 2ᵏ = 2^(k+1).
Example: n³ − n is divisible by 3
  1. Basis P(1): 1³ − 1 = 0, divisible by 3.
  2. Assume 3 | (k³ − k). Expand (k + 1)³ − (k + 1) = (k³ − k) + 3(k² + k).
  3. Both terms are divisible by 3, so the sum is divisible by 3.

4. Practice exercises ★

  • Prove 1·1! + 2·2! + … + n·n! = (n + 1)! − 1.
  • Prove 2 − 2·7 + 2·7² − … + 2(−7)ⁿ = (1 − (−7)^(n+1))/4 for n ≥ 0.
  • Prove the geometric sum a + ar + … + arⁿ = a(r^(n+1) − 1)/(r − 1).
  • Prove 2ⁿ < n! for n ≥ 4, starting the basis at 4.
  • Prove 7^(n+2) + 8^(2n+1) is divisible by 57 for n ≥ 0.

Part 2 · Strong Induction and Well Ordering ★★★

Pages 5–6 of the chapter PDF.

1. Strong induction ★★★

Use strong induction when ordinary induction is not enough. The basis step is the same, P(1). The inductive step assumes P(j) for all j = 1, 2, …, k and proves P(k + 1):

(P(1) ∧ P(2) ∧ … ∧ P(k)) → P(k + 1).

It is also called the second principle of mathematical induction or complete induction.

Example: every integer greater than 1 is a product of primes
  1. Basis P(2): 2 is a product of one prime, itself.
  2. Assume P(j) for 2 ≤ j ≤ k. Consider k + 1.
  3. If k + 1 is prime, done. Otherwise k + 1 = ab with 2 ≤ a ≤ b < k + 1.
  4. By the hypothesis a and b are products of primes, hence so is k + 1.

2. Well-ordering property ★★★

Every nonempty set of nonnegative integers has a least element.

Division algorithm via well ordering

Let S = {a − dq | q ∈ Z} ∩ {nonnegative integers}. S is nonempty, so it has least element r = a − dq. If r ≥ d then a − d(q + 1) = r − d ≥ 0 would be a smaller element, a contradiction. Hence 0 ≤ r < d and a = dq + r with q and r unique.

Part 3 · Recursive Definitions and Structural Induction ★★★

Pages 6–8 of the chapter PDF.

1. Recursively defined functions ★★★ EXAM 1

Define a function on nonnegative integers in two steps: a basis step gives its value at 0, and a recursive step gives its value at n from smaller values. A sequence a₀, a₁, … is the same object: aₙ = f(n).

f(0) = 3, f(n + 1) = 2f(n) + 3
  1. f(1) = 2·3 + 3 = 9.
  2. f(2) = 2·9 + 3 = 21.
  3. f(3) = 2·21 + 3 = 45.
  4. f(4) = 2·45 + 3 = 93.
Recursive definition of aⁿ

Basis: a⁰ = 1. Recursive step: aⁿ⁺¹ = a · aⁿ for n = 0, 1, 2, …. Together these uniquely define aⁿ for every nonnegative n.

2. Recursively defined sets ★★★

A recursive set definition has a basis step (initial elements), a recursive step (rules for new elements), and sometimes an exclusion rule saying nothing else belongs.

Set S: 3 ∈ S, and x, y ∈ S implies x + y ∈ S

Basis gives 3. One application gives 6 = 3 + 3. Two applications give 9 = 3 + 6 and 12 = 6 + 6. The set is the positive multiples of 3.

Well-formed formulae

Basis: T, F, and propositional variables are well-formed. Recursive step: if E and F are well-formed, so are (¬E), (E ∧ F), (E ∨ F), (E → F), (E ↔ F).

3. Structural induction ★★★ EXAM 1

StepObligation
BasisProve the statement for every element in the basis step of the set definition
RecursiveAssume it for the components used to build new elements, then prove it for those new elements
Balanced parentheses in every well-formed formula
  1. Basis: T, F, s have no parentheses, so counts are equal.
  2. Assume p and q have lₚ = rₚ and l_q = r_q.
  3. Each compound adds one left and one right parenthesis, so equality is preserved.

Part 4 · Recursive Algorithms ★★★

Pages 8–9 of the chapter PDF.

1. Three model algorithms ★★★

An algorithm is recursive when it solves a problem by reducing it to an instance of the same problem with smaller input.

Factorial

n! = n · (n − 1)! for n > 0 and 0! = 1. Trace: 5! = 5·4!, 4! = 4·3!, …, 1! = 1·0!, then work back to 5! = 120.

procedure factorial(n: nonnegative integer)
if n = 0 then return 1
else return n · factorial(n − 1)

Power

aⁿ⁺¹ = a · aⁿ for n > 0, with a⁰ = 1. Reduce the exponent to zero, then work back.

procedure power(a: nonzero real, n: nonnegative integer)
if n = 0 then return 1
else return a · power(a, n − 1)

Greatest common divisor

Use gcd(a, b) = gcd(b mod a, a) with gcd(0, b) = b. Example: gcd(14, 21) = gcd(7, 14) = gcd(0, 7) = 7.

procedure gcd(a, b: nonnegative integers with a < b)
if a = 0 then return b
else return gcd(b mod a, a)

2. Proving correctness ★★★ EXAM 2

Use ordinary or strong induction to show a recursive algorithm produces the desired output for every input.

Proof that power(a, n) = aⁿ
  1. Basis: n = 0 returns 1, and a⁰ = 1 for every nonzero a.
  2. Inductive hypothesis: power(a, k) = aᵏ.
  3. Then power(a, k + 1) = a · power(a, k) = a · aᵏ = a^(k+1).
  4. Therefore the algorithm is correct for a ≠ 0 and n ≥ 0.
