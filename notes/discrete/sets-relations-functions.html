Part 1 · Sets ★★★

Unit 1 of the chapter PDF.

1. Definition and notation ★★★ EXAM 1

A set is an unordered collection of objects, called elements or members. We write a ∈ A when a is an element of A and a ∉ A when it is not. Uppercase letters name sets; lowercase letters name elements.

NotationMeaningExample
Roster / list methodList members between bracesV = {a, e, i, o, u}
Set builderState the property members satisfyO = {x ∈ Z⁺ | x is odd and x < 10}
EllipsisPattern continues{1, 2, 3, …, 79}
Equal setsA = B iff ∀x(x ∈ A ↔ x ∈ B){1, 3, 5} = {3, 5, 1}

Order and repetition do not matter. {1, 3, 3, 3, 5, 5} = {1, 3, 5}. The empty set ∅ has no elements; {∅} is a singleton whose one element is the empty set. That confusion is the most common error in this unit.

2. Important sets, subsets, size ★★★

SetContents
N{0, 1, 2, 3, …} natural numbers
Z / Z⁺Integers / positive integers
Q{p/q | p ∈ Z, q ∈ Z, q ≠ 0} rationals
R / R⁺ / CReals / positive reals / complex numbers
  • Subset: A ⊆ B iff ∀x(x ∈ A → x ∈ B). To disprove it, find one x ∈ A with x ∉ B, a counterexample.
  • Theorem: ∅ ⊆ S and S ⊆ S for every set S. The first holds vacuously.
  • Proper subset: A ⊂ B iff A ⊆ B and A ≠ B, i.e. ∀x(x ∈ A → x ∈ B) ∧ ∃x(x ∈ B ∧ x ∉ A).
  • Equality via subsets: A = B iff A ⊆ B and B ⊆ A.
  • Cardinality: a finite set with n distinct elements has |S| = n. The null set has cardinality 0.
Why ∅ ⊆ S needs no elements checked

The conditional x ∈ ∅ → x ∈ S has a false hypothesis for every x, so the implication is always true. That is a vacuous proof.

3. Power sets and Cartesian products ★★★ EXAM 1

P(S) is the set of all subsets of S. If |S| = n then |P(S)| = 2ⁿ.

P({0, 1, 2}) and the two empty-set cases
  • P({0, 1, 2}) = {∅, {0}, {1}, {2}, {0, 1}, {0, 2}, {1, 2}, {0, 1, 2}}.
  • P(∅) = {∅}, while P({∅}) = {∅, {∅}}.

Cartesian product: A × B = {(a, b) | a ∈ A and b ∈ B}. Ordered pairs satisfy (a₁, a₂) = (b₁, b₂) iff a₁ = b₁ and a₂ = b₂. In general A × B ≠ B × A; equality requires A = ∅ or B = ∅.

A = {1, 2}, B = {a, b, c}: compute A × B, A², A³
  1. A × B = {(1, a), (1, b), (1, c), (2, a), (2, b), (2, c)}.
  2. A² = {(1, 1), (1, 2), (2, 1), (2, 2)}.
  3. A³ has the eight triples (1, 1, 1), (1, 1, 2), …, (2, 2, 2).

Venn diagrams use a rectangle for the universe U and circles for sets. Union shades either circle, intersection shades the overlap, difference shades A outside B.

Worked example: {1, 3, 5} and {1, 2, 3}

Union {1, 2, 3, 5}; intersection {1, 3}; difference {1, 3, 5} − {1, 2, 3} = {5}.

6. Computer representation of sets ★★★

Fix an ordering of U = {a₁, …, aₙ}. Represent A ⊆ U by a bit string of length n: bit i is 1 exactly when aᵢ ∈ A. Complement flips bits; union is bitwise OR; intersection is bitwise AND.

U = {1, 2, …, 10}: three bit strings
  • Odd integers {1, 3, 5, 7, 9} → 1010101010.
  • Even integers {2, 4, 6, 8, 10} → 0101010101.
  • Integers ≤ 5 {1, 2, 3, 4, 5} → 1111100000.

Union of the last two: 1111101010 = {1, 2, 3, 4, 5, 7, 9}. Intersection: 1010100000 = {1, 3, 5}.

Part 2 · Relations ★★★

Unit 2 of the chapter PDF.

1. Binary relations and counting ★★★ EXAM 2

A binary relation R from A to B is a subset of A × B. We write aRb for (a, b) ∈ R and a R̸ b for (a, b) ∉ R. A relation on A is a subset of A × A.

  • A function f: A → B is a relation whose graph {(a, b) | b = f(a)} has exactly one pair for each a ∈ A.
  • A relation can express one-to-many; a function cannot. Relations generalize graphs of functions.
  • A set with n elements has n² ordered pairs in A × A, hence 2^(n²) relations on A.
R = {(a, b) | a divides b} on {1, 2, 3, 4}

R = {(1, 1), (1, 2), (1, 3), (1, 4), (2, 2), (2, 4), (3, 3), (4, 4)}. Display it as a table with rows a and columns b, marking 1 where a | b.

2. Properties of relations ★★★

PropertyQuantifier formMatrix / digraph test
Reflexive∀a((a, a) ∈ R)All diagonal entries 1; loop at every vertex
Symmetric∀a∀b((a, b) ∈ R → (b, a) ∈ R)M = Mᵀ; reverse edge for every edge
Antisymmetric((a, b) ∈ R ∧ (b, a) ∈ R) → a = bNever two opposite edges between distinct vertices
Transitive(a, b) ∈ R ∧ (b, c) ∈ R → (a, c) ∈ REdge x→y and y→z forces x→z

Symmetric and antisymmetric are not opposites. A relation with only pairs (a, a) has both. A relation on ℝ given by a − b ∈ Z is reflexive, symmetric, and transitive.

Closure of R = {(1, 3), (1, 4), (2, 1), (3, 2)} on {1, 2, 3, 4}
  1. Not transitive: (1, 3) and (3, 2) are in R but (1, 2) is not.
  2. Add (1, 2), (2, 3), (2, 4), (3, 1), then repeat until no new pair appears.
  3. Final transitive closure contains all pairs with first component 1, 2, or 3 and any second component from 1 to 4.

3. Combining relations and closures ★★★

  • Composite: S ∘ R = {(a, c) | ∃b ∈ B, (a, b) ∈ R ∧ (b, c) ∈ S}.
  • Powers: R¹ = R and Rⁿ⁺¹ = Rⁿ ∘ R.
  • Reflexive closure: R ∪ Δ where Δ = {(a, a) | a ∈ A}.
  • Symmetric closure: R ∪ R⁻¹ where R⁻¹ = {(b, a) | (a, b) ∈ R}.
  • Transitive closure: repeatedly add (a, c) whenever (a, b) and (b, c) are present.
Closures of R = {(1, 1), (1, 2), (2, 1), (3, 2)} on {1, 2, 3}
  1. Reflexive: add (2, 2) and (3, 3) → R ∪ Δ.
  2. Symmetric: add (2, 1) already present, then (1, 3) and (3, 1) → R ∪ R⁻¹.
  3. Transitive: add (1, 1), (2, 2), (3, 1), (3, 3) and repeat.

4. Representing relations ★★ EXAM 2

Four representations: list of ordered pairs, table, zero–one matrix, directed graph. For A = {a₁, …, aₘ}, B = {b₁, …, bₙ}, the matrix has mᵢⱼ = 1 exactly when (aᵢ, bⱼ) ∈ R.

  • Set operations on matrices: M_{R₁∪R₂} = M_{R₁} ∨ M_{R₂}; M_{R₁∩R₂} = M_{R₁} ∧ M_{R₂}.
  • Composite via Boolean product: M_{S∘R} = M_R ⊙ M_S; powers use Boolean powers M_{Rⁿ} = (M_R)ⁿ.
  • Digraph: vertices and ordered edges; (a, a) is a loop. Properties read off loops, reverse edges, and shortcuts.

5. Equivalence relations and partial orders ★★★ EXAM 2

  • Equivalence relation: reflexive, symmetric, transitive. Write a ~ b. Equivalence class [a] = {s | (a, s) ∈ R}. Classes partition the set into disjoint nonempty subsets.
  • Example: a = b or a = −b on Z gives [a] = {−a, a}, so [7] = {−7, 7} and [0] = {0}.
  • Partial order: reflexive, antisymmetric, transitive. (A, R) is a poset. ≥ on Z is a poset.
  • The divides relation on positive integers is reflexive and transitive but not symmetric, so not an equivalence relation.

6. n-ary relations and databases ★★

An n-ary relation is a subset of A₁ × … × Aₙ with degree n and domains A₁, …, Aₙ. A relational database is a collection of tables of records (n-tuples) with fields. A primary key is a domain with no duplicate value across tuples. Operations: selection S_C, projection P_{i₁,…,iₘ}, and join J_p. SQL performs all of these.

Part 3 · Functions ★★★

Unit 3 of the chapter PDF.

1. Definitions and terminology ★★★

A function f: A → B assigns exactly one element of B to each element of A. Its graph {(a, b) | b = f(a)} is a subset of A × B. A is the domain, B the codomain; if f(a) = b then b is the image of a and a a preimage of b. The range is the set of all images.

TermMeaningExample (grading)
DomainInput set A{Ram, Shyam, Gita, Rita}
CodomainTarget set B{A, B, C, D, F}
RangeSet of images{A, C, D}
Image of S ⊆ Af(S) = {f(s) | s ∈ S}f({b, c, d}) = {1, 4}

Equal functions have the same domain, codomain, and mapping. For real- or integer-valued functions with common domain, define (f₁ + f₂)(x) = f₁(x) + f₂(x) and (f₁f₂)(x) = f₁(x)f₂(x).

2. Injective, surjective, bijective ★★★ EXAM 2

A strictly increasing or strictly decreasing function is one-to-one. A merely increasing function need not be. f(x) = x² from Z to Z is neither one-to-one nor onto; f(x) = x + 1 from Z to Z is bijective.

3. Inverse and composition ★★★

  • Inverse: if f is a bijection, f⁻¹(b) = a exactly when f(a) = b.
  • Composition: (f ∘ g)(a) = f(g(a)); defined only when range(g) ⊆ domain(f).
  • f⁻¹ ∘ f = ι_A, f ∘ f⁻¹ = ι_B, and (f⁻¹)⁻¹ = f.
f(x) = 2x + 3, g(x) = 3x + 2
  1. (f ∘ g)(x) = f(3x + 2) = 2(3x + 2) + 3 = 6x + 7.
  2. (g ∘ f)(x) = g(2x + 3) = 3(2x + 3) + 2 = 6x + 11.

4. Floor, ceiling, Boolean and exponential functions ★★★ EXAM 4

FunctionDefinitionKey property
Floor ⌊x⌋Largest integer ≤ x⌊x⌋ = n iff n ≤ x < n + 1
Ceiling ⌈x⌉Smallest integer ≥ x⌈x⌉ = n iff n − 1 < x ≤ n
Booleanf: Bⁿ → B with B = {0, 1}Complement, OR, AND
Exponentialf_b(n) = bⁿb^(x+y) = bˣbʸ, (bˣ)ʸ = b^(xy)

Useful identities: x − 1 < ⌊x⌋ ≤ x ≤ ⌈x⌉ < x + 1, ⌊−x⌋ = −⌈x⌉, and ⌊x + n⌋ = ⌊x⌋ + n for integer n.

Two counting examples
  1. Bytes for 100 bits: ⌈100/8⌉ = ⌈12.5⌉ = 13 bytes.
  2. ATM cells for 30,000,000 bits at 424 bits per cell: ⌊30,000,000/424⌋ = 70,754 cells.
Boolean algebra on {0, 1}

Complement: 0̄ = 1, 1̄ = 0. Boolean sum (OR): 1 + 1 = 1. Boolean product (AND): 1 · 0 = 0. Bⁿ contains all n-tuples of 0s and 1s; a function Bⁿ → B has degree n.
