Part 1 · Propositional Logic ★★★

Pages 1–4 of the chapter PDF.

1. Introduction ★

Rules of logic give precise meaning to mathematical statements and separate valid arguments from invalid ones. Applications named in the chapter: computer circuit design, program construction, and program correctness verification.

2. Propositions ★★★ EXAM 2

Definition. A proposition is a declarative sentence that is either true or false, but not both.

PropositionTruth value
Kathmandu is the capital of Nepal.True
2 + 2 = 5.False
1 + 1 = 2.True

Not propositions. “x > 3”; “What time is it?”; “Read this carefully.”; “x + y = z”, not declarative, or truth cannot be judged.

Propositions use lowercase letters p, q, r, s … Truth values are T and F. The field is propositional logic, also called propositional calculus, developed systematically by Aristotle more than 2300 years ago.

3. Logical operators / connectives ★★★

OperatorKey ruleTruth behaviorPriority
Negation ¬p“I love birds” → “I do not love birds”T→F, F→T★★★
Conjunction p ∧ qp = “Ram is intelligent”, q = “Ram is diligent”True only when both are true★★★
Disjunction p ∨ qSame exampleFalse only when both are false★★★
Exclusive or p ⊕ q“Ram drinks coffee or tea in the morning”True only when exactly one is true★★
Implication p → qp = hypothesis / antecedent / premise; q = conclusion / consequenceFalse only when p is true and q is false★★★
Biconditional p ↔ q“p if and only if q”True when p and q share a truth value★★★

3.5 Implication, alternative wordings ★★★

Memorize: “if p, then q”; “q if p”; “p is sufficient for q”; “q when p”; “a necessary condition for p is q”; “q unless ¬p”; “p implies q”; “p only if q”; “p is necessary for q”; “q whenever p”; “q follows from p”.

  • Converse: q → p
  • Inverse: ¬p → ¬q
  • Contrapositive: ¬q → ¬p

Key result. An implication and its contrapositive are equivalent, always the same truth value. Exercise: show “if it is hot today then today is Sunday” and “if it is not Sunday then it is not hot” are equivalent.

3.6 Biconditional wordings ★★★

“p if and only if q”; “if p then q, and conversely”; “p is necessary and sufficient for q”; “p iff q”.

4. Precedence of logical operators ★★

Highest to lowest: ¬ → ∧ → ∨ → → ↔. Use parentheses whenever the intended order could be unclear.

5. Worked examples ★★

a) Truth table for (p ∨ ¬q) → (p ∧ q)
pq¬qp ∨ ¬qp ∧ q(p ∨ ¬q) → (p ∧ q)
TTFTTT
TFTTFF
FTFFFT
FFTTFF
b) English translation

p = “it rained last night”, q = “the sprinklers came on last night”, r = “the lawn was wet this morning”.

  • ¬p = “it didn’t rain last night”
  • r ∧ ¬p = “the lawn was wet this morning and it didn’t rain last night”
  • ¬r ∨ p ∨ q = “either the lawn was not wet this morning or it rained last night or the sprinklers came on last night”
c) Evaluate with p = T, q = F, r = T
  1. ¬r ∨ ¬(p ∧ q) = F ∨ ¬(T ∧ F) = F ∨ T = T (true).
  2. ¬(p ∨ q) ∧ (¬r ∨ q) = ¬(T ∨ F) ∧ (F ∨ F) = F ∧ F = F (false).

6. Translating English to propositional logic ★★★

  1. Restate the sentence into building-block sentences.
  2. Give each building block a symbol.
  3. Substitute the symbols using connectives.

Example: “if it is snowing then I will go to the beach” → p = “it is snowing”, q = “I will go to the beach”, written p → q.

2. Logical equivalences ★★★

p and q are logically equivalent, written p ⇔ q or p ≡ q, exactly when p ↔ q is a tautology.

LawFormula
Identityp ∧ T ⇔ p; p ∨ F ⇔ p
Dominationp ∧ F ⇔ F; p ∨ T ⇔ T
Idempotentp ∧ p ⇔ p; p ∨ p ⇔ p
Double negation¬(¬p) ⇔ p
Commutativep ∧ q ⇔ q ∧ p; p ∨ q ⇔ q ∨ p
Associative(p ∧ q) ∧ r ⇔ p ∧ (q ∧ r); (p ∨ q) ∨ r ⇔ p ∨ (q ∨ r)
Distributivep ∧ (q ∨ r) ⇔ (p ∧ q) ∨ (p ∧ r); p ∨ (q ∧ r) ⇔ (p ∨ q) ∧ (p ∨ r)
De Morgan¬(p ∧ q) ⇔ ¬p ∨ ¬q; ¬(p ∨ q) ⇔ ¬p ∧ ¬q
Negationp ∧ ¬p ⇔ F; p ∨ ¬p ⇔ T
Absorptionp ∨ (p ∧ q) ⇔ p; p ∧ (p ∨ q) ⇔ p
Equivalences with → and ↔

p → q ⇔ ¬p ∨ q; p → q ⇔ ¬q → ¬p; p ∨ q ⇔ ¬p → q; p ∧ q ⇔ ¬(p → ¬q); ¬(p → q) ⇔ p ∧ ¬q; (p → q) ∧ (p → r) ⇔ p → (q ∧ r); (p → r) ∧ (q → r) ⇔ (p ∨ q) → r; (p → q) ∨ (p → r) ⇔ p → (q ∨ r); (p → r) ∨ (q → r) ⇔ (p ∧ q) → r; p ↔ q ⇔ (p → q) ∧ (q → p); p ↔ q ⇔ ¬p ↔ ¬q; p ↔ q ⇔ (p ∧ q) ∨ (¬p ∧ ¬q); ¬(p ↔ q) ⇔ p ↔ ¬q.

3. Proving logical equivalence ★★★

Method 1, truth table. Two propositions are equivalent iff their truth-value columns agree. Example: (p → q) ∧ (p → ¬q) ≡ ¬p.

Method 2, symbolic derivation

Prove ¬(p ∨ (¬p ∧ q)) ⇔ ¬p ∧ ¬q.

  1. ¬(p ∨ (¬p ∧ q)) ≡ ¬p ∧ ¬(¬p ∧ q), De Morgan
  2. ≡ ¬p ∧ [¬(¬p) ∨ ¬q], De Morgan
  3. ≡ ¬p ∧ (p ∨ ¬q), Double negation
  4. ≡ (¬p ∧ p) ∨ (¬p ∧ ¬q), Distributive
  5. ≡ F ∨ (¬p ∧ ¬q), Negation
  6. ≡ (¬p ∧ ¬q) ∨ F, Commutative
  7. ≡ ¬p ∧ ¬q, Identity
Exercises from the chapter
  1. Use a truth table to show p → q ≡ ¬p ∨ q.
  2. Show (p ∧ q) → (p ∨ q) is a tautology using both methods.
  3. Symbolically derive (p → q) ∧ (p → ¬q) ⇔ ¬p.

Part 3 · Predicates and Quantifiers ★★★

Pages 7–11 of the chapter PDF.

1. Introduction ★★

Propositional logic cannot adequately express all statements in mathematics or natural language. Predicate logic adds predicates and quantifiers.

2. Predicate ★★★ EXAM 3

Statements with variables are neither true nor false until values are assigned. P(x) is a propositional function: P = predicate, x = variable / subject.

  • P(x): x > 3 → P(3) is false, P(7) is true.
  • Q(x, y): x = y + 3 → Q(1, 2) is false, Q(3, 0) is true.
Exercise: R(x, y, z) = “x + y = z”

Find the truth values of R(1, 2, 3) and R(0, 0, 1).

3. Quantifiers ★★★ EXAM 3

QuantifierMeaningEssence
Universal ∀P(x) is true for all values of x in the universe of discourse∀x P(x) = P(x₁) ∧ P(x₂) ∧ … ∧ P(xₙ)
Existential ∃P(x) is true for at least one value of x∃x P(x) = P(x₁) ∨ P(x₂) ∨ … ∨ P(xₙ)

Counterexample rule. One value with P(x) false disproves ∀x P(x). Example: x² > 0 fails for x = 0 over the integers.

Exercise 2: P(x) = “x > 10”, domain = positive integers not exceeding 4

Judge ∃x P(x).

4. Precedence of quantifiers ★★

∀ and ∃ bind more tightly than all propositional operators: ∀x P(x) ∨ Q(x) means (∀x P(x)) ∨ Q(x).

5. Binding variables ★★★

A variable is bound when assigned a value or quantified; otherwise it is free.

  • P(x, y), two free variables.
  • P(2, y), x bound, y free.
  • ∀x P(x), x bound.
  • ∀x P(x, y), x bound, y free.

Expression with no free variable is a proposition; with at least one free variable it is a predicate only.

6. Negation of quantified expressions ★★★ EXAM 1

¬∀x P(x) ≡ ∃x ¬P(x). “Every girl in Kathmandu is lovely” negates to “there is a girl in Kathmandu who is not lovely.”

¬∃x P(x) ≡ ∀x ¬P(x).

7. Translating English into logic ★★★

There is no cookbook approach. Work from the examples:

  • Every student in this class has studied calculus → ∀x C(x), or ∀x (S(x) → C(x)) over all people.
  • Some student in this class has visited Mexico → ∃x M(x).
  • Every student has visited either Canada or Mexico → ∀x (C(x) ∨ M(x)).
  • Not every integer is even → ¬∀x E(x).

8. Nested quantifiers ★★★

Quantifiers inside the scope of other quantifiers, such as ∀x ∃y P(x, y).

FormMeaning with L(x, y) = “x loves y”
∀x ∃y L(x, y)Everybody loves someone
∃y ∀x L(x, y)There is a person loved by everyone
∃x ∀y L(x, y)Someone loves all the people
∀y ∃x L(x, y)Everyone has someone who loves her / him
∀x ∀y L(x, y)Everybody loves everyone
∃x ∃y L(x, y)Someone loves somebody
English → nested quantifiers

Female and parent ⇒ someone’s mother: ∀x (F(x) ∧ P(x) → ∃y M(x, y)), equivalently ∀x∃y(F(x) ∧ P(x) → M(x, y)).

Everyone has exactly one best friend: ∀x∃y (B(x, y) ∧ ∀z (B(x, z) → (y = z))).

Negating nested quantifiers

¬(∀y ∃x P(x, y)) = ∃y (¬∃x P(x, y)) = ∃y ∀x ¬P(x, y).

Part 4 · Rules of Inference ★★★

Pages 12–16 of the chapter PDF.

1. Introduction ★★

Rules of inference are templates for valid arguments. An argument is valid when all true hypotheses force a true conclusion.

2. Rules for propositional logic ★★★ EXAM 3

RuleFormPriority
Modus Ponensp, p → q ∴ q★★★
Hypothetical Syllogismp → q, q → r ∴ p → r★★★
Additionp ∴ p ∨ q★★

Conjunctionp, q ∴ p ∧ q★★
Modus Tollens¬q, p → q ∴ ¬p★★★
Disjunctive Syllogismp ∨ q, ¬p ∴ q★★
Constructive Dilemma(p → q) ∧ (r → s), p ∨ r ∴ q ∨ s★
Destructive Dilemma(p → q) ∧ (r → s), ¬q ∨ ¬s ∴ ¬p ∨ ¬r★

Worked examples

Modus Ponens: “Ram is hard working” + “if Ram is hard working, then he is intelligent” ⇒ “Ram is intelligent.”

Hypothetical Syllogism: Sunday → rainy day → wet today ⇒ “if today is Sunday, then it is wet today.”

3. Fallacies ★★★

Fallacies are convincing but incorrect arguments; they are contingencies, not tautologies.

  • Affirming the conclusion: p → q, q ∴ p.
  • Denying the hypothesis: p → q, ¬p ∴ ¬q.

4. Valid arguments ★★★

Valid ⇔ (p₁ ∧ p₂ ∧ … ∧ pₖ) → q is a tautology. A valid argument with false premises may still yield a false conclusion.

Full 12-step derivation, “It rained”

p = “It rains”, q = “It is foggy”, r = “the sailing race is held”, s = “Life saving demonstration is done”, t = “Trophy is awarded”.

  1. r → t, Hypothesis
  2. ¬t, Hypothesis
  3. ¬r, Modus Tollens (1, 2)
  4. (¬p ∨ ¬q) → (r ∧ s), Hypothesis
  5. ¬(¬p ∨ ¬q) ∨ (r ∧ s), Implication (4)
  6. (p ∧ q) ∨ (r ∧ s), De Morgan (5)
  7. p ∨ (r ∧ s), Simplification (6)
  8. p ∨ r, Simplification (7)
  9. r ∨ p, Commutative (8)
  10. ¬r ∨ p, Addition (3)
  11. p ∨ p, Resolution (9, 10)
  12. p, Idempotent (11)
Hockey example

p = “I play hockey”, q = “I am sore”, r = “I use the whirlpool”. From p → q and q → r, hypothetical syllogism gives p → r; with ¬r, modus tollens gives ¬p, “I did not play hockey.”

6. Inference with quantified statements ★★★

Example 1, Hari
  1. ∀x (D(x) → C(x)), Premise
  2. D(Hari) → C(Hari), Universal instantiation
  3. D(Hari), Premise
  4. C(Hari), Modus ponens
Example 2, 9-step quantified derivation

Premises: ∃x (C(x) ∧ ¬B(x)) and ∀x (C(x) → P(x)). Conclusion: ∃x (P(x) ∧ ¬B(x)).

  1. ∃x (C(x) ∧ ¬B(x)), Premise
  2. C(a) ∧ ¬B(a), Existential instantiation
  3. C(a), Simplification
  4. ∀x (C(x) → P(x)), Premise
  5. C(a) → P(a), Universal instantiation
  6. P(a), Modus ponens
  7. ¬B(a), Simplification
  8. P(a) ∧ ¬B(a), Conjunction
  9. ∃x (P(x) ∧ ¬B(x)), Existential generalization

Part 5 · Methods of Proof ★★★

Pages 17–22 of the chapter PDF.

1. Terminology ★★

A proof is a valid argument establishing a mathematical statement. A theorem is an important fact; a proposition is a less important theorem; a lemma helps prove other results; a corollary follows directly from a theorem; a conjecture is proposed truth until proved or disproved.

2. Methods of proving p → q ★★★ EXAM 5

MethodCore ideaPriority
Direct proofAssume p; show q★★★
Indirect proofProve contrapositive ¬q → ¬p★★★
Vacuous proofp is false, so p → q is true★★
Trivial proofq is always true★★
ContradictionAssume p ∧ ¬q; derive a contradiction★★★
Exhaustive / casesProve (p₁ ∨ … ∨ pₙ) → q case by case★★
EquivalenceProve both p → q and q → p★★★
Direct proof, odd n ⇒ odd n²

n = 2k + 1 ⇒ n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, which is odd.

Indirect proof, 3n + 2 odd ⇒ n odd

Assume n even: n = 2k. Then 3n + 2 = 6k + 2 = 2(3k + 1), even. Contrapositive proves the claim.

Proof by contradiction, a² even ⇒ a even

Assume a² even and a odd: a = 2k + 1. Then a² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, odd, contradiction.

Exhaustive proof, (n + 1)³ ≥ 3n for n ≤ 4

Check n = 1, 2, 3, 4: 8 ≥ 3; 27 ≥ 9; 64 ≥ 27; 125 ≥ 81.

Proof of equivalence, n even iff 7n + 4 even

If n = 2k, then 7n + 4 = 2(7k + 2), even. If n = 2k + 1, then 7n + 4 = 2(7k + 5) + 1, odd; hence 7n + 4 even implies n even.

3. Theorems and quantifiers ★★★

3.1 Existence proofs ★★

  • Constructive: exhibit the element, 2500 = 50² and 2601 = 51² bound 100 consecutive non-squares.
  • Nonconstructive: prove existence without producing the element, irrational x, y with xʸ rational; x⁵ + 2x³ + x − 7 = 0 in (0, 2) by the Intermediate Value Theorem.

3.2 Uniqueness proofs ★★

Form: ∃x (P(x) ∧ ∀y (y ≠ x → ¬P(y))). Show existence, then show any y ≠ x lacks the property. Example: if a ≠ 0, ax + b = c has unique solution x = (c − b) / a.

4. Proofs by counterexamples ★★★

To disprove ∀x P(x), find one x with P(x) false. Example: √2 · √2 = 2, so the product of two irrationals is not necessarily irrational.

5. Mistakes in proofs ★

Most common errors are arithmetic and algebra mistakes. Every step must follow logically. The most common fallacy is begging the question, circular reasoning.
