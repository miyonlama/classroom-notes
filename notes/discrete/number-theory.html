Part 1 · Divisibility and Modular Arithmetic ★★★

Pages 1–6 of the chapter PDF.

1. Divisibility ★★★

For integers a ≠ 0 and b, a divides b when b = ac for some integer c, written a | b. Then a is a factor or divisor of b and b is a multiple of a. Quantifier form: ∃c(ac = b).

ResultStatement
Theorem 1(i)a | b ∧ a | c → a | (b + c)
Theorem 1(ii)a | b → a | bc for every integer c
Theorem 1(iii)a | b ∧ b | c → a | c
Corollary 1a | mb + nc for all integers m, n when a | b and a | c

Theorem 1 is proved by direct proof: write b = as and c = at, then b + c = a(s + t). The number of positive integers not exceeding n that are divisible by d is ⌊n/d⌋.

2. Division algorithm ★★★ EXAM 1

Theorem 2: for integer a and positive integer d there are unique integers q and r with 0 ≤ r < d and a = dq + r. Here d is divisor, a dividend, q quotient, r remainder; q = a div d and r = a mod d.

For positive d, a div d = ⌊a/d⌋ and a mod d = a − d⌊a/d⌋. The remainder cannot be negative, and d | a exactly when the remainder is 0.

Two worked divisions
  1. 101 = 11·9 + 2, so 101 div 11 = 9 and 101 mod 11 = 2.
  2. −11 = 3(−4) + 1, so −11 div 3 = −4 and −11 mod 3 = 1.

3. Congruences and arithmetic modulo m ★★★ EXAM 2

a is congruent to b modulo m when m | (a − b), written a ≡ b (mod m). Equivalently a and b have the same remainder on division by m.

ResultStatement
Theorem 3a ≡ b (mod m) iff a mod m = b mod m
Theorem 4a ≡ b (mod m) iff a = b + km for some integer k
Theorem 5a ≡ b, c ≡ d → a + c ≡ b + d and ac ≡ bd (mod m)
Corollary 2(a + b) mod m = ((a mod m) + (b mod m)) mod m

The congruence class of a modulo m is the set of all integers congruent to a. On Zₘ = {0, 1, …, m − 1}, define a +ₘ b = (a + b) mod m and a ·ₘ b = (a · b) mod m.

Clock and Z₁₁ examples
  1. 50 hours after 11:00: (11 + 50) mod 24 = 13, so 13:00.
  2. 7 +₁₁ 9 = 16 mod 11 = 5; 7 ·₁₁ 9 = 63 mod 11 = 8.
  3. 16 ≡ 4 (mod 6) since 6 | 12; 23 ≢ 13 (mod 6) since 6 ∤ 10.

Part 2 · Integer Representations and Algorithms ★★★

Pages 7–11 of the chapter PDF.

1. Base b expansions ★★★

Theorem 6: for b > 1, every positive integer n has a unique expansion n = aₖbᵏ + … + a₁b + a₀ with 0 ≤ aᵢ < b and aₖ ≠ 0. Written (aₖ … a₀)_b.

BaseDigitsWorked example
2 (binary)0, 1; a bit string(10101111)₂ = 351
8 (octal)0–7(7016)₈ = 3598
16 (hexadecimal)0–9, A–F(2AE0B)₁₆ = 175627

Conversion to base b uses repeated division; remainders give digits from right to left. Octal groups three binary digits, hexadecimal groups four.

Conversions
  1. 12345 = 8·1543 + 1, 1543 = 8·192 + 7, 192 = 8·24 + 0, 24 = 8·3 + 0, 3 = 8·0 + 3 → (30071)₈.
  2. 241 → (11110001)₂; 177130 → (2B3EA)₁₆.
  3. (111101011100)₂ groups as 011 110 101 111 100 → (37274)₈.
  4. (A5D)₁₆ = 1010 0101 1101 → (101001011101)₂.

2. Algorithms for binary arithmetic ★★★

  • Addition: add rightmost bits with carry: aⱼ + bⱼ + c = 2d + sⱼ, set c = d. Example (1110)₂ + (1011)₂ = (11001)₂.
  • Multiplication: form partial products a·bⱼ·2ʲ, then add. Example (110)₂ × (101)₂ = (11110)₂.
  • div and mod: repeatedly subtract d from |a|, count as q; if a < 0 and r > 0 return −(q + 1) and d − r.
div/mod algorithm trace
  1. 11 div 4: r = 11 → 7 → 3, q = 0 → 1 → 2, so q = 2, r = 3.
  2. −11 div 4: start r = 11 → 7 → 3 with q = 2, then a < 0 and r > 0 gives r = 3 − 4 = −1, q = −(2 + 1) = −3.

Part 3 · Primes, GCD, and Congruences ★★★

Pages 12–17 of the chapter PDF.

1. Primes and factorization ★★★ EXAM 1

A prime is an integer greater than 1 with exactly two positive divisors, 1 and itself. n is composite iff some a satisfies a | n and 1 < a < n.

  • Fundamental Theorem of Arithmetic: every integer > 1 is uniquely a product of primes in nondecreasing order. 200 = 2³·5², 999 = 3³·37.
  • Theorem 8: a composite n has a prime divisor ≤ √n.
  • Trial division: n is prime if no prime ≤ √n divides it. 101 is prime since 2, 3, 5, 7 do not divide it.
  • Prime factorization: 7007 = 7·7·11·13 = 7²·11·13.

2. GCD, LCM, and the Euclidean algorithm ★★★ EXAM 2

gcd(a, b) is the largest integer dividing both; lcm(a, b) the smallest positive multiple of both. From prime factorizations, gcd uses min exponents and lcm uses max exponents. Theorem 9: ab = gcd(a, b) · lcm(a, b).

Factorization and Euclidean examples
  1. 120 = 2³·3·5, 500 = 2²·5³ → gcd = 2²·5 = 20, lcm = 2³·3·5³ = 3000.
  2. Euclidean: 662 = 414·1 + 248, 414 = 248·1 + 166, 248 = 166·1 + 82, 166 = 82·2 + 2, 82 = 2·41 → gcd(414, 662) = 2.
  3. Lemma 1: if a = bq + r then gcd(a, b) = gcd(b, r), because common divisors divide r = a − bq and conversely.

3. Bézout coefficients ★★★

Bézout's Theorem: for positive a, b there exist integers s, t with gcd(a, b) = sa + tb. Find them by back-substitution through the Euclidean divisions, or by the extended Euclidean algorithm in one forward pass.

gcd(252, 198) = 18 = 4·252 − 5·198
  1. 252 = 1·198 + 54; 198 = 3·54 + 36; 54 = 1·36 + 18; 36 = 2·18.
  2. 18 = 54 − 36 = 54 − (198 − 3·54) = 4·54 − 198.
  3. Substitute 54 = 252 − 198: 18 = 4·252 − 5·198.

4. Linear congruences and CRT ★★★ EXAM 3

A linear congruence has the form ax ≡ b (mod m). If gcd(a, m) = 1 then a has a unique inverse modulo m, found from Bézout coefficients sa + tm = 1; multiply both sides by s.

Solve 3x ≡ 4 (mod 7)
  1. 7 = 2·3 + 1, so 1 = −2·3 + 1·7 and −2 is an inverse of 3 modulo 7.
  2. Multiply: −6x ≡ −8 (mod 7), so x ≡ 6 (mod 7).
  3. Solutions are x = 6, 13, 20, … and −1, −8, −15, ….

Chinese Remainder Theorem: for pairwise relatively prime moduli m₁, …, mₙ, the system x ≡ aᵢ (mod mᵢ) has a unique solution modulo m = m₁…mₙ. Compute Mₖ = m/mₖ, find yₖ with Mₖyₖ ≡ 1 (mod mₖ), then x = Σ aₖMₖyₖ.

x ≡ 2 (mod 3), x ≡ 3 (mod 5), x ≡ 2 (mod 7)
  1. m = 105; M₁ = 35, M₂ = 21, M₃ = 15.
  2. Inverses: y₁ = 2, y₂ = 1, y₃ = 1.
  3. x = 2·35·2 + 3·21·1 + 2·15·1 = 233 ≡ 23 (mod 105).

CRT also represents large integers by n-tuples of remainders. Adding 123,684 and 413,456 modulo 99, 98, 97, 95 gives componentwise (65, 2, 51, 10), which solves back to 537,140.

1. Zero-one matrices and Boolean operations ★★★ EXAM 2

An m × n matrix is a rectangular array; square means m = n. A zero-one matrix has only 0 and 1 entries and uses Boolean arithmetic.

OperationDefinition
Join A ∨ BEntry aᵢⱼ ∨ bᵢⱼ
Meet A ∧ BEntry aᵢⱼ ∧ bᵢⱼ
Boolean product A ⊙ Bcᵢⱼ = (aᵢ₁ ∧ b₁ⱼ) ∨ … ∨ (aᵢₖ ∧ bₖⱼ)
Boolean power A^[r]A ⊙ … ⊙ A (r factors); A^[0] = Iₙ

The Boolean product mirrors ordinary multiplication with OR replacing addition and AND replacing multiplication. Zero-one matrices represent relations, so these operations compute unions, intersections, composites, and powers of relations.
