1. Graph types ★★★ EXAM 3

A graph G = (V, E) has a nonempty set of vertices V and a set of edges E, each edge connecting one or two endpoints. Graphs model competition, influence, tournaments, telephone calls, web links, road networks, circuit layout, and shortest paths.

TypeEdgesMultipleLoops

MultigraphUndirectedYesNo
PseudographUndirectedYesYes
Simple directed graphDirectedNoNo
Directed multigraphDirectedYesYes
Mixed graphBothYesYes

A directed edge (u, v) starts at u and ends at v. A loop joins a vertex to itself. A simple directed graph has no loops and no repeated directed edges.

2. Degree and the handshaking theorem ★★★

  • u and v are adjacent (neighbors) when {u, v} is an edge; the edge is incident with both endpoints.
  • Neighborhood N(v) is the set of neighbors of v; for A ⊆ V, N(A) = ⋃ N(v) over v ∈ A.
  • Degree deg(v) counts incident edges, with a loop counting twice. Degree 0 is isolated; degree 1 is pendant.
  • Handshaking theorem: 2m = Σ deg(v) for an undirected graph with m edges.
  • An undirected graph has an even number of odd-degree vertices.
Worked degree example

Six vertices of degree 6 and one of degree 10 give a degree sum of 6·6 + 10 = 60, so the graph has m = 30 edges.

For directed graphs, deg⁻(v) counts edges ending at v and deg⁺(v) counts edges starting at v. A loop adds one to each. Σ deg⁻(v) = Σ deg⁺(v) = |E|.

3. Special graphs and bipartite graphs ★★★

GraphDefinition
KₙComplete graph, one edge between every pair of distinct vertices
CₙCycle on n ≥ 3 vertices
WₙWheel: Cₙ plus one hub vertex joined to every cycle vertex
Qₙn-cube: 2ⁿ bit strings, adjacent when they differ in one bit

A simple graph is bipartite when V splits into disjoint V₁ and V₂ with every edge joining the two parts. Equivalently, the vertices can be two-colored with no adjacent vertices sharing a color, or no closed walk uses an odd number of edges. K_{m,n} joins every vertex of an m-set to every vertex of an n-set. C₆ is bipartite; K₃ is not.

4. Representations and isomorphism ★★★ EXAM 3

Represent a graph by listing edges, an adjacency list, an adjacency matrix A(G) with aᵢⱼ = 1 when {vᵢ, vⱼ} is an edge, or an incidence matrix with mᵢⱼ = 1 when edge eⱼ is incident with vᵢ.

  • Adjacency matrices of undirected graphs are symmetric. For multigraphs an entry is the number of edges between the pair.
  • Incidence columns for parallel edges are identical; a loop has a column with only one nonzero entry.
  • A sparse graph is often better stored as an adjacency list.
  • Isomorphism: a bijection f: V₁ → V₂ preserving adjacency. Graph invariants are vertex count, edge count, and degree sequence. Matching invariants does not prove isomorphism.

5. Paths and connectivity ★★★ EXAM 2

A path of length n is a sequence of n edges joining x₀ to xₙ. If x₀ = xₙ the path is a circuit. A simple path or circuit repeats no edge. An undirected graph is connected when every pair of vertices has a path; its maximal connected pieces are connected components.

  • Every pair of vertices in a connected undirected graph has a simple path between them.
  • A cut vertex (articulation point) is a vertex whose removal increases the number of components. A cut edge (bridge) is an edge whose removal does the same.
  • A directed graph is strongly connected when paths exist both ways between every pair; weakly connected when the underlying undirected graph is connected. Maximal strongly connected subgraphs are strong components.

6. Euler and Hamilton paths ★★★ EXAM 4

An Euler circuit is a simple circuit using every edge; an Euler path is a simple path using every edge.

ResultCondition
Euler circuitConnected multigraph, all vertices of even degree
Euler path but no circuitConnected multigraph, exactly two vertices of odd degree
Hamilton circuitSimple circuit through every vertex exactly once
Dirac's theoremn ≥ 3 and deg(v) ≥ n/2 for all v implies a Hamilton circuit
Ore's theoremn ≥ 3 and deg(u) + deg(v) ≥ n for all nonadjacent u, v implies a Hamilton circuit
Why even degrees force an Euler circuit

Passing through a vertex contributes two to its degree and the final return to the start contributes one more, giving even degrees. Conversely, splice subcircuits into a growing circuit until every edge is used.

Hamilton terminology comes from Hamilton's 1857 Icosian puzzle. Euler's work came from the Königsberg bridge problem.

7. Shortest paths and coloring ★★★ EXAM 3

In a weighted graph each edge carries a number. Dijkstra's algorithm finds a shortest path in a connected graph with positive weights: set L(a) = 0 and all other labels to ∞; repeatedly take an unvisited vertex u with minimal label, add it to S, and relax every neighbor v via L(v) = min(L(v), L(u) + w(u, v)).

The travelling salesperson problem asks for a minimum-weight Hamilton circuit in a complete weighted graph; checking all (n − 1)!/2 circuits is impractical, and no efficient algorithm is known.

A coloring assigns colors to vertices so adjacent vertices differ. The chromatic number χ(G) is the least number of colors: χ(Kₙ) = n, χ(K_{m,n}) = 2, and χ(Cₙ) = 2 for even n and 3 for odd n > 1. Map coloring uses the dual graph, whose chromatic number is at most four. Exam scheduling colors courses, with adjacent courses sharing a student.

1. Trees and rooted trees ★★★

A tree is a connected undirected simple graph with no simple circuits. A forest is a disconnected graph whose components are trees. An undirected graph is a tree exactly when there is a unique simple path between any two vertices.

A rooted tree designates one vertex as the root and directs every edge away from it. For a vertex v, its parent is the unique predecessor, children are its successors, siblings share a parent, ancestors lie on the root-to-v path, and descendants have v as an ancestor. Leaves have no children; internal vertices do. The subtree at v contains v and all descendants.

An m-ary tree has at most m children per internal vertex; a full m-ary tree has exactly m. A binary tree has m = 2. An ordered rooted tree arranges children left to right. The level of v is its distance from the root, the height is the maximum level, and a tree of height h is balanced when all leaves sit at levels h or h − 1.

2. Binary search trees, decisions, prefix codes ★★★

A binary search tree labels vertices with keys so that each key exceeds every key in its left subtree and is below every key in its right subtree. Insertion starts at the root and moves left or right until the new key can be attached.

A decision tree has a decision at each internal vertex and a subtree for each outcome; solutions are paths to leaves. In the seven-coin counterfeit problem each weighing has three outcomes, so the decision tree is 3-ary and two weighings suffice.

A prefix code assigns bit strings so no codeword is a prefix of another. In a binary code tree, a left edge is 0 and a right edge is 1; the code for a letter is the edge-label sequence from the root to its leaf. Huffman coding builds such codes for data compression.

3. Tree traversal ★★★ EXAM 2

TraversalOrder
PreorderVisit root, then each subtree left to right
InorderTraverse first subtree, visit root, then remaining subtrees
PostorderTraverse all subtrees left to right, then visit root

Each traversal is defined recursively on the ordered rooted tree. Preorder exposes the root first; postorder visits it last.

4. Spanning trees and Kruskal's algorithm ★★★ EXAM 4

A spanning tree of a simple connected graph is a subgraph that is a tree containing every vertex. A graph is connected if and only if it has a spanning tree. A minimum spanning tree in a connected weighted graph minimizes the sum of edge weights.

Kruskal's algorithm: begin with an empty graph; repeatedly add the lightest edge that creates no simple circuit; stop after n − 1 edges.

Why connected iff spanning tree
  1. If a spanning tree exists, its paths between all vertex pairs are also paths in the original graph, so the graph is connected.
  2. If the graph is connected but not a tree, it has a simple circuit. Delete one circuit edge.
  3. Repeat until no circuit remains. All vertices are still present and connected, giving a spanning tree.

Minimum spanning trees appear in computer, telecommunications, and transportation networks, power grids, circuit design, and broadcasting trees.
