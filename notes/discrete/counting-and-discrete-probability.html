1. Product, sum, and subtraction rules ★★★

Four product-rule examples
  1. 27 floors × 37 offices = 999 offices.
  2. Three-letter initials with no repeats: 26·25·24 = 15,600.
  3. Four-letter strings containing x: 26⁴ − 25⁴ = 456,976 − 390,625 = 66,351.
  4. Bit strings of length 5: 2⁵ = 32.

The sum rule applies only to disjoint sets. For overlapping sets use inclusion–exclusion.

Bit strings of length 8 starting with 1 or ending in 00

2⁷ + 2⁶ − 2⁵ = 128 + 64 − 32 = 160. The overlap is the strings that start with 1 and end with 00.

2. Pigeonhole principle ★★★ EXAM 4

Theorem 1: if k + 1 or more objects go into k boxes, some box holds at least two objects. Proof by contradiction: if every box held at most one, the total would be at most k. Also called the Dirichlet drawer principle.

Corollary 1: a function from a set with k + 1 elements to a set with k elements is not one-to-one.

Theorem 2 (generalized): N objects in k boxes force a box with at least ⌈N/k⌉ objects.

Three generalized examples
  1. 100 people, 12 months: at least ⌈100/12⌉ = 9 share a birth month.
  2. 24 students and k grades: ⌈24/k⌉ = 2 gives largest k = 23.
  3. Five grades and at least six sharing: smallest N with ⌈N/5⌉ = 6 is N = 26.

4. Binomial coefficients ★★★

Binomial Theorem: (x + y)ⁿ = Σₖ₌₀ⁿ C(n, k) x^(n−k) yᵏ.

Pascal's Identity: C(n + 1, k) = C(n, k − 1) + C(n, k). It builds Pascal's triangle: each entry is the sum of the two above it.

  • Σₖ C(n, k) = 2ⁿ (set x = y = 1).
  • Σₖ (−1)ᵏ C(n, k) = 0 (set x = 1, y = −1).
  • Σₖ 2ᵏ C(n, k) = 3ⁿ (set x = 1, y = 2).
Expansions and coefficients
  1. (x + y)⁴ = x⁴ + 4x³y + 6x²y² + 4xy³ + y⁴.
  2. Coefficient of x¹²y¹³ in (2x − 3y)²⁵ is C(25, 13)·2¹²·(−3)¹³.

6. Generating arrangements ★★

For permutations in lexicographic order, locate the last adjacent pair with aᵢ < aᵢ₊₁, replace aᵢ by the least larger element to its right, then list the rest increasingly. After 362541 comes 364125.

Subsets correspond to bit strings. Starting at 00…0, find the first 0 from the right and change all 1s after it to 0: after 100010011 comes 100010100.

For r-combinations, locate the last aᵢ with aᵢ ≠ n − r + i, increment it, and reset the following entries. After {1, 2, 5, 6} of {1, …, 6} comes {1, 3, 4, 5}.

1. Recurrence relations ★★★ EXAM 5

A recurrence relation expresses aₙ in terms of earlier terms for all n ≥ n₀. The initial conditions and the recurrence together define the sequence; a sequence is a solution when its terms satisfy the relation.

Checking candidate solutions
  1. aₙ = −3aₙ₋₁ + 4aₙ₋₂ is not satisfied by aₙ = 2n: the right side gives 2n − 10.
  2. aₙ = 2aₙ₋₁ − aₙ₋₂ is satisfied by aₙ = 3n: 2·3(n − 1) − 3(n − 2) = 3n.
  3. Bacteria doubling aₙ = 2aₙ₋₁ with a₀ = 5 gives aₙ = 5·2ⁿ.
  4. Compound interest Pₙ = 1.11Pₙ₋₁ with P₀ = 10,000 gives P₃₀ = (1.11)³⁰·10,000 = $228,922.97.

2. Linear homogeneous relations ★★★ EXAM 5

Form: aₙ = c₁aₙ₋₁ + … + cₖaₙ₋ₖ with constant cᵢ. Substitute aₙ = rⁿ to obtain the characteristic equation rᵏ − c₁rᵏ⁻¹ − … − cₖ = 0.

  1. Characteristic r² − r − 6 = 0 gives roots 3 and −2.
  2. aₙ = α₁3ⁿ + α₂(−2)ⁿ; a₀ = 3 gives α₁ + α₂ = 3.
  3. a₁ = 6 gives 3α₁ − 2α₂ = 6, so α₁ = 12/5 and α₂ = 3/5.
  4. Solution: aₙ = (12·3ⁿ + 3(−2)ⁿ)/5.
Repeated root: aₙ = 2aₙ₋₁ − aₙ₋₂, a₀ = 3, a₁ = 6

r² − 2r + 1 = 0 has the single root 1, so aₙ = α₁ + α₂n. Initial values give α₁ = α₂ = 3, hence aₙ = 3(1 + n).

Multiple roots and multiplicity

aₙ = 2aₙ₋₁ + aₙ₋₂ − 2aₙ₋₃ has roots 1, −1, 2 and solution aₙ = (3/2)1ⁿ − (1/2)(−1)ⁿ + 2·2ⁿ. For aₙ = 5aₙ₋₁ − 7aₙ₋₂ + 3aₙ₋₃, root 1 has multiplicity 2: aₙ = (α₁₀ + α₁₁n)1ⁿ + α₂₀3ⁿ.

3. Linear nonhomogeneous relations ★★★

Form: aₙ = c₁aₙ₋₁ + … + cₖaₙ₋ₖ + F(n). Dropping F(n) gives the associated homogeneous relation.

  • Theorem 5: every solution equals a particular solution plus a solution of the associated homogeneous relation.
  • Theorem 6: for F(n) = (polynomial of degree t)·sⁿ, try (polynomial of degree t)·sⁿ when s is not a characteristic root, and nᵐ times that when s is a root of multiplicity m.
aₙ = 4aₙ₋₁ + n²
  1. Homogeneous root 4 gives aₙ⁽ʰ⁾ = α4ⁿ.
  2. Try pₙ = an² + bn + c; matching coefficients gives a = −1/3, b = −8/9, c = −20/27.
  3. All solutions: aₙ = −n²/3 − 8n/9 − 20/27 + α4ⁿ. With a₁ = 1, α = 20/27.
When s is a root: aₙ = 2aₙ₋₁ + n·2ⁿ

Here s = 2 is a root of multiplicity 1, so try n(p₁n + p₀)2ⁿ. All solutions have the form α2ⁿ + p₁n²2ⁿ + p₀n2ⁿ.

Part 3 · Discrete Probability ★★★

Pages 20–25 of the chapter PDF.

1. Finite probability ★★★

An experiment yields one of a set of outcomes; the sample space S is that set; an event E is a subset of S. For a finite nonempty sample space of equally likely outcomes, Laplace's definition gives p(E) = |E| / |S|, with 0 ≤ p(E) ≤ 1.

  • Fair die, odd number: p = 3/6 = 1/2.
  • Urn with 4 blue and 5 red balls: p(blue) = 4/9.
  • Complement: p(Ē) = 1 − p(E). Ten random bits, at least one 0: 1 − 1/1024 = 1023/1024.
  • Union: p(E₁ ∪ E₂) = p(E₁) + p(E₂) − p(E₁ ∩ E₂). Integers ≤ 100 divisible by 2 or 5: 50/100 + 20/100 − 10/100 = 3/5.

2. Assigning probabilities ★★★

A probability distribution assigns p(s) to each outcome with 0 ≤ p(s) ≤ 1 and Σ p(s) = 1. The uniform distribution gives 1/n to each outcome; choosing at random means uniform.

Biased coin and biased die
  1. p(H) = 2p(T) and p(H) + p(T) = 1 ⇒ p(T) = 1/3, p(H) = 2/3.
  2. Die with 3 twice as likely: five faces at 1/7 and face 3 at 2/7; p({1, 3, 5}) = 1/7 + 2/7 + 1/7 = 4/7.

3. Conditional probability and independence ★★★

For p(F) > 0, the conditional probability of E given F is p(E | F) = p(E ∩ F) / p(F). Events E and F are independent exactly when p(E ∩ F) = p(E)p(F).

Three fair coin flips

E = odd number of tails, F = first flip is tail. E ∩ F = {THH, TTT}, so p(E ∩ F) = 2/8 and p(F) = 4/8. Hence p(E | F) = (1/4)/(1/2) = 1/2.

Families with two children

E = two boys {BB}, F = at least one boy {BB, BG, GB}. p(E) = 1/4, p(F) = 3/4, p(E ∩ F) = 1/4 ≠ 3/16, so E and F are not independent.

Worked expectations
  1. Fair die: E(X) = (1 + 2 + 3 + 4 + 5 + 6)/6 = 7/2.
  2. Three flips, X = number of heads: E(X) = 12/8 = 3/2.
  3. Fair die variance: E(X²) = 91/6, so V(X) = 91/6 − (7/2)² = 35/12.

5. Hashing and randomized algorithms ★★ EXAM 3

A hashing function maps keys to storage locations; a collision maps two different keys to one location. The probability that n keys all land in different locations among m is pₙ = (m − 1)(m − 2)…(m − n + 1) / m^(n−1), so the probability of at least one collision is 1 − pₙ.
