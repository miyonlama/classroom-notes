Questions from the nine past papers (2078–2082). Frequency and marks are transcribed from Past Questions.pdf. Answers will be added after review.

What does “congruent modulo” mean? Determine whether 20 ≡ 8 (mod 6) and whether 25 ≡ 17 (mod 5).

Frequency: 2078 (Q8) · Marks: 5

Definition. For integers a, b and positive integer m, a ≡ b (mod m) means m divides a − b, equivalently a and b have the same remainder on division by m.

For 20 ≡ 8 (mod 6): 20 − 8 = 12 = 2·6, so the congruence holds.

For 25 ≡ 17 (mod 5): 25 − 17 = 8, which is not divisible by 5, so the congruence is false. Indeed 25 ≡ 0 and 17 ≡ 2 (mod 5).

Explain trial division with an example. Using trial division, show that 101 is prime.

Frequency: 2078 (Q9) · Marks: 5

Trial division. To test whether n is prime, divide n by each prime p ≤ √n. If none divides n then n is prime, because any composite factorisation n = ab must have one factor at most √n.

Example. 91 is composite: √91 ≈ 9.5 and 91 = 7 × 13.

For 101: √101 ≈ 10.05, so test the primes 2, 3, 5, 7. 101 is odd; its digit sum is 2, so 3 does not divide it; it does not end in 0 or 5; and 101 = 7·14 + 3. No prime up to √101 divides 101, so 101 is prime.

What is arithmetic modulo m? Using the definitions of addition and multiplication in Zₘ, compute 7 +₁₁ 9 and 7 ×₁₁ 9.

Frequency: 2079 (Q9) · Marks: 5

In Zₘ the elements are the residue classes {0, 1, …, m − 1}. Addition and multiplication are performed on representatives and the result reduced modulo m: [a]ₘ + [b]ₘ = [a + b]ₘ and [a]ₘ · [b]ₘ = [ab]ₘ. These operations are well defined because replacing a representative by an equivalent one changes results by a multiple of m.

Working modulo 11:

  • 7 +₁₁ 9 = 16, and 16 = 11 + 5, so the answer is 5.
  • 7 ×₁₁ 9 = 63, and 63 = 5·11 + 8, so the answer is 8.

Z₁₁ is a field because 11 is prime: every nonzero class has a multiplicative inverse.

Prove that √2 is irrational.

Frequency: 2080.1 (Q7), 2082 (Q2) · Marks: 5

Method: Proof by Contradiction (Indirect Proof)

Step 1 — State the assumption. Assume the opposite of what we need to prove: suppose √2 is a rational number.

Step 2 — Define the rational number. By the definition of rational numbers, write √2 in its simplest form as √2 = a/b, where a and b are integers, b ≠ 0, and a and b have no common factor other than 1, that is gcd(a, b) = 1 (they are coprime).

Step 3 — Algebraic manipulation. Square both sides: 2 = a²/b². Multiply both sides by b²: a² = 2b² — Equation 1.

Step 4 — Deduce that a is even. From Equation 1, a² is an integer multiplied by 2, so a² is even. If the square of an integer is even, the integer itself is even. Hence a is even, and we may write a = 2k for some integer k.

Step 5 — Deduce that b is even. Substitute a = 2k into Equation 1: (2k)² = 2b², so 4k² = 2b², and dividing by 2 gives 2k² = b². By the same logic as Step 4, b² is even, so b is even.

Step 6 — State the contradiction. Both a and b are even, so they share a common factor of 2. This contradicts Step 2, where a and b were chosen coprime with gcd(a, b) = 1.

Conclusion. The assumption leads to a logical impossibility, so it is false. Therefore √2 is irrational.

Solve the system of congruences using the Chinese Remainder Theorem: x ≡ 2 (mod 3), x ≡ 3 (mod 5), x ≡ 2 (mod 7).

Frequency: 2080.1 (Q8) · Marks: 5

Use the Chinese Remainder Theorem with M = 3·5·7 = 105 and pairwise coprime moduli.

  1. For mod 3: M₁ = 35, and 35 ≡ 2 (mod 3). Since 2·2 ≡ 1 (mod 3), the inverse is 2; contribution 2·35·2 = 140.
  2. For mod 5: M₂ = 21 ≡ 1 (mod 5), inverse 1; contribution 3·21·1 = 63.
  3. For mod 7: M₃ = 15 ≡ 1 (mod 7), inverse 1; contribution 2·15·1 = 30.

Sum = 140 + 63 + 30 = 233, and 233 − 2·105 = 23. Hence x ≡ 23 (mod 105). Check: 23 = 7·3 + 2, 23 = 4·5 + 3, 23 = 3·7 + 2. The solution is unique modulo 105.

Explain how the Chinese Remainder Theorem can be used to perform computations on large integers and give an example.

Frequency: 2080.2 (Q9) · Marks: 5

The Chinese Remainder Theorem represents an integer x by its residues modulo several pairwise coprime moduli m₁, …, mₖ. Since reduction is a ring homomorphism, (x + y) mod mᵢ = (x mod mᵢ) + (y mod mᵢ) and similarly for products. Large integers can therefore be added or multiplied componentwise on small residues, then recovered uniquely modulo M = m₁⋯mₖ.

Example. With moduli 9, 10, 11 (pairwise coprime, M = 990), 1234 has residues (1, 4, 2): its digit sum is 10, so 1234 ≡ 1 (mod 9), its last digit gives 4, and the alternating sum 4 − 3 + 2 − 1 = 2 gives mod 11. Also 56 has residues (2, 6, 1). Adding componentwise, their sum has residues (3, 0, 3), which reconstructs to 300 (mod 990). This agrees with 1234 + 56 = 1290 = 990 + 300.

This is used in modular arithmetic libraries and cryptography: computations stay on small numbers while the modulus M can be enormous.

Find the multiplicative inverse of 6 in Z₂₅ using the extended Euclidean algorithm.

Frequency: 2081 (Q6) · Marks: 5

Apply the Euclidean algorithm to 25 and 6: 25 = 4·6 + 1. Hence 1 = 25 − 4·6, so −4·6 ≡ 1 (mod 25).

Since −4 ≡ 21 (mod 25), the multiplicative inverse of 6 in Z₂₅ is 21. Check: 6·21 = 126 = 5·25 + 1 ≡ 1 (mod 25). The inverse exists because gcd(6, 25) = 1.

Compute the following values: 8 mod 8, −9 mod 4, 7 mod 17, 6 mod 7, and −8 mod 3.

Frequency: 2081 (Q9) · Marks: 5

Reduce each value to the least nonnegative residue in the relevant range:

  • 8 mod 8 = 0, since 8 = 1·8 + 0.
  • −9 mod 4: add 12 to reach 3, so −9 ≡ 3 (mod 4).
  • 7 mod 17 = 7, already in range.
  • 6 mod 7 = 6, already in range.
  • −8 mod 3: add 9 to reach 1, so −8 ≡ 1 (mod 3).

Rule: a mod m is the remainder r with 0 ≤ r < m and a = qm + r, even when a is negative (choose q negative enough).

State the division algorithm. Add the integers 13,578 and 45,730 using the Chinese Remainder Theorem.

Frequency: 2082 (Q1) · Marks: 2+8

Division algorithm. For integers a and b > 0 there exist unique integers q and r with a = bq + r and 0 ≤ r < b; q is the quotient and r the remainder.

Adding with CRT. Choose pairwise coprime moduli 9, 10, 11, whose product is 990.

  • 13,578 has residues (6, 8, 4): digit sum 24 → 6 mod 9; last digit 8; and alternating sum 8 − 7 + 5 − 3 + 1 = 4 mod 11.
  • 45,730 has residues (1, 0, 3): digit sum 19 → 1 mod 9; last digit 0; alternating sum 0 − 3 + 7 − 5 + 4 = 3 mod 11.

Add componentwise to get (7, 8, 7). Solving x ≡ 7 (mod 9), x ≡ 8 (mod 10), x ≡ 7 (mod 11) gives x ≡ 898 (mod 990). Direct addition confirms 13,578 + 45,730 = 59,308 = 59·990 + 898, so the residue reconstruction agrees with the ordinary sum.
